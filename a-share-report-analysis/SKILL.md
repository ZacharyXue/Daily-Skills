# A股财报 PDF 分析

用户常直接把公司年报/中报 PDF 放到服务器（如 `/tmp/<公司>/`）让我读。目标产出不是流水账，而是按固定维度讲透一家公司：**商业模式 → 几块业务(占比/毛利率) → 利润趋势 → 现金流质量 → 股东回报 → 优点/风险清单 → 一句话结论**。

## 工作流

### Step 1: 提取 PDF 全文

```bash
pip install pymupdf   # 若未安装
python3 scripts/extract_report_txt.py 2024年报.pdf 2025年报.pdf 2026中报.pdf
```

产出 `*.txt`，每页带 `=== PAGE N ===` 标记，方便后续用 grep 锚点定位后回读上下文。

### Step 2: grep 锚点定位关键章节

| 想要的数据 | grep 锚点 | 说明 |
|-----------|-----------|------|
| 核心业绩指标 | `主要会计数据和财务指标` | 营业收入/归母净利/扣非/经营现金流/基本每股收益/加权ROE 全在这一块，年报含 3 年列、中报含上年同期列 |
| 有多少业务 | `营业收入构成` + `分行业` `分产品` `分地区` | 各业务收入、占比、同比；分地区看区域集中度 |
| 分产品毛利率 | `占公司营业收入或营业利润10%以上的行业` | ⚠️ 毛利率主表不在这里就在"营业收入构成"后，注意每行有收入/成本/毛利率/3个同比 |
| 现金流 | `经营活动产生的现金流量净额` | 找现金流量表三大活动净额；质量=经营现金流/净利润 比值 |
| 分红 | `利润分配预案` / `每10股` / `现金分红` | 全年分红在年报；中报通常"不派现" |
| 股东回报政策 | `现金分红政策的专项说明` | 分红率承诺、成熟期定位、回购 |
| 风险 | `公司未来发展的展望` `风险因素` | 周期性/区域/贸易摩擦等 |
| 主营描述 | `公司主要业务、产品和用途` | 商业模式段落：产品、应用领域、产能、储量、营运主体 |

### Step 3: 建跨年数据表

把 2-3 年 + 最新中报的营收/净利/扣非/经营现金流/EPS/ROE/总资产/净资产排成表，看趋势再动笔。周期股的"同比暴增"必须结合上游价格（铝价/煤价等）解释。

### Step 5: 同行对比（用户说"看看同行"时）

用东方财富 datacenter API 拉同行财务摘要，**免费无 key**。完整配方、字段字典、脚本骨架、实例表格见 `references/eastmoney-peer-compare.md`。

要点：
- pageSize 必须 ≥20（默认只返回最新 1-2 期，拿不到年报）
- **报告期口径必须对齐**：各家最新披露期不同（神火中报 vs 他家一季报），统一取"2025年报"再辅以"2026一季报"看拐点，别直接比最新一期
- 区分"同行业不同物种"：纯冶炼 vs 加工厂（明泰毛利率 7%）vs 一体化，别拿毛利率直接对标

### Step 6: 利润拆解（用户要"利润和盈利能力的构成"时）

拆两层：
1. **归母口径传导链**：子公司汇总净利 − 少数股东损益 = 归母净利。持股 <100% 的大利润子公司=隐形"分红税"（如云南神火持股仅 58.25%），合并净利会高估股东能拿到的钱。
2. **盈利能力驱动 = 量 × 价 × 成本差**：产能/产销量（满产满销=无积压）、售价上涨、成本同比 vs 收入同比的剪刀差（神火 2026H1 收入+21% 成本-3.3% → 毛利翻倍）；再往下毛利→三费→所得税瀑布。

### Step 7: 按用户固定维度输出（顺序不要改）

1. **商业模式与主营业务** — 公司定位一句话 + 各业务表格（收入、占比、毛利率、说明）；煤电铝一体化这类"X-Y-Z一体化"成本护城河是重点
2. **业绩趋势** — 跨年表 + 关键解读（为什么涨/跌）
3. **现金流质量** — 经营/投资/筹资 + 经营现金流÷净利润 比值（>1 为高质量）
4. **股东回报** — 每股分红、分红总额、分红率、股息率、回购、股权激励
5. **综合结论** — 优点✅ / 风险⚠️ 清单 + 一句话总结
6. 结尾主动给出下一步可深挖方向（风险章节原文、负债细节、同行业对比等）

## Pitfalls

- **pymupdf 用 `import pymupdf`**，`import fitz` 会打 deprecated 警告（仍可用但别依赖）。
- **PDF 表格提取为逐行文本**：表头行和数值行分离，数值后面常紧跟单位行；按行顺序配对，别跳行。大额数字单位是"元"，汇报时换算成"亿元"。
- **年报"主要会计数据"是 3 年宽表**（本年/上年/前年），读同比增减要看准列；中报是"本报告期/上年同期"2 列。
- **"分行业毛利率"段落**跟在"占营业收入或营业利润10%以上的行业"后面，不叫"毛利率"标题，直接 grep `毛利率` 可能漏。
- **中报"计划不派现"是常态**，不是坏事；分红看年末年报的利润分配预案。
- **毛利率增减列是百分点**（如 +85.03），不是百分比，转述时说"增加了 X 个百分点"。
- 周期性资源股（铝/煤/钢铁）：当前毛利率处于历史高位时要明说"赚的是周期钱不是成长钱"，别让结论误导为成长股。
- 引用的财务数字全部来自报告原文，给出表格即可；用户后续会追问细节，保留 txt 供回查。

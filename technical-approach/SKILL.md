# 技术面 skill — 操作层（择时 × 仓位 × 纪律）

**分工**：`stock-analysis` 回答「**买什么**」（基本面/价值漏斗）；本 skill 回答「**何时买、买多少、何时卖、怎么分散**」（操作层）。基本面读完 → 用本 skill 定操作；两者合起来才是完整决策。

> 体系来源：陪读《超级鹿鼎公414.pdf》（第8/10/16/21/27/32/33/42/48/57/58/90/95/130章），六环：价值漏斗 → 难死掉三条件 → 垄断三层威胁 → 趋势开关 → 三层止损 → 仓位/杠杆纪律。前两环在 `stock-analysis` 与 `dividend-asset-framework` 弹药(references/redli-framework.md)，本 skill 承接后三环（趋势/止损/仓位）。

## 趋势系统（均线）

| 均线 | 含义 | 适配 |
|---|---|---|
| 60日线 | 一季度趋势 | L2 周期个股（敏感） |
| 120日线 | 半年趋势 | L1 ETF / 中线持仓（默认） |
| 250日线 | 牛熊分界 | L0 指数大开大合 |

- **买入**：收盘站上对应均线 + MA60(>MA120) 金叉确认
- **卖出**：跌破对应均线 **且** MA60(>MA120) 死叉——**单均线会假摔，必须双确认**
- **纪律三连**：①破位卖完不反手（等重新金叉再回场）②信号失效才回场 ③配合仓位（仓位轻到不用止损才是最优）

## 三层止损（认错 vs 割肉）

- **认错=逻辑止损**（"我错了"）：买入理由被证伪 / 企业从"很难死掉"变"可能死掉" / 仓位过重 → 无条件走
- **割肉=价格止损**（"我亏了"）：因为亏了 X% 而卖 / 恐慌 / 想换股搏一把 → **不做**
- 三层次序：**仓位管理（第一层）→ 趋势止损（第二层，破位+死叉）→ 逻辑止损（第三层）**；机械幅度止损（-20%）只在杠杆/仓位失控时兜底，不是常态纪律
- 记忆点：卖出看**逻辑/市场结构**，不看亏损幅度；PE/TTM 在 E 暴涨或暴跌时都失真，别用"低PE"解释一切

## 分散持有

- 单一个股 ≤ **10%** 总仓位；单一行业 ≤ **25%**；同一逻辑（如"都是电解铝"）算同行业
- "分散的是仓位，不只是注意力"——研究可以集中，持仓必须分散
- 周期股永不上重仓（波动可 -30%+）

## 仓位/杠杆纪律（四大死法，按致命性排序）

1. **杠杆**（万劫不复）→ 防御：永不借入资金买股票；盘面回撤>20% 停手一周，禁止"加杠杆翻本"
2. **集中**（万劫不复）→ 防御：单一个股≤10%、单一行业≤25%（同上）
3. **没耐心**（慢性病，难赚钱）→ 防御：只在难死掉企业里持股，波动当噪音；止损锚用趋势/逻辑不用幅度
4. **高负债股**（可选风险，前置过滤）→ 防御：42章5点法"业绩2-5年无下降风险"不满足的高负债股不进池子（看错毁灭速度极快：万科/地产案例）

**复利不对称**（撑起整个纪律的数学）：赚50%需跌33%抹平；赚100%跌50%抹平；一次-50%回撤毁掉十年积累的一半。→「不亏损」不是保守，是复利方程的解。

## 风控线（每一层通用）

1. 不满足信号 → 空仓/持有，禁止手痒
2. 周期股永不上重仓
3. 周期股左侧三选二才动手，单信号不买
4. 指数破 250 日线 → 当天清理杠杆/融资

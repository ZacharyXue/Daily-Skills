# 分层择时（L0 指数 / L1 ETF / L2 周期个股）

> 原则：**价值漏斗先筛掉不合格的 → 趋势信号只在合格池子里用 → 大部分时间信号是「不动」**。
> 三层划分依据：资产性质不同，择时逻辑不同——指数无个股基本面问题（纯趋势+流动性）；ETF 反映指数（估值分位+跌透）；周期个股 PE 失真（锚在成本和供给出清）。

## L0 指数层（沪深300 / 中证500 / 创业板）

- **做多**：收盘站上 250 日线 且 MA60(>MA120)（周线级牛市确认）
- **离场**：跌破 250 日线 → 空仓/仅底仓
- **辅助**：10年国债收益率位置（钱便宜 → 估值水位抬升）
- 数据：`achieve('kline', symbol='sh000300')`

## L1 ETF层（红利 515180/159545、成长 159259、游戏 159869、电池 159796、黄金、标普500、纳指100）

- **买入（双条件）**：估值分位<20%（5年PB/PE）**且** 距250日高点回撤≥15~20%（分位数据源见 dividend-asset-framework 弹药）
- **持有**：回撤<10% 且 250日线上方
- **加仓**：趋势确认（金叉）且仍在低估区
- **离场**：跌破 250 日线 且 估值回到中位上方
- 口诀：「低位涨了顺势加仓，高位大涨了逢高出货」（鹿鼎公第10章）

## L2 周期个股（神火/煤炭/电解铝、商品）

- **禁入**：利润高增期（毛利率加速上行、归母净利+100%以上）、PB分位>30%、趋势高位
- **左侧买入（供给出清三选二，可观察信号，禁止用"企稳"这种事后词）**：
  1. 全行业亏损：商品价 < 行业中位成本，多数企业现金流转负
  2. 高成本产能退出：停产公告、开工率下降、不再新增产能
  3. 价格贴近成本线长时间横盘 + 库存去化
- **同时**：PB 分位<30%（用 `financial_series` 的 BPS 对齐历史价格算分位）
- **为什么看供给不看需求**：需求是快变量不可观测（见时新闻已被定价）；供给是慢变量可观测；成本线=周期底部锚（价格不会长期低于全行业边际成本）

## 风控（通用）

1. 不满足信号 → 空仓/持有，禁止手痒
2. 周期股永不上重仓
3. 左侧三选二才动手
4. 指数破 250 日线 → 清理杠杆

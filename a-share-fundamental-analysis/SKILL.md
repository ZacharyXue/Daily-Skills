# A股财报分析（年报/中报 PDF → 基本面 → 同行对比 → 风险排查）

用户给上市公司年报/中报 PDF 时的高效分析流程。核心：PDF 提文本 → grep 导航章节 → 提取财务指标 → 东财 API 拉同行 → 成本/风险拆解。

## 工作流

### Step 1: PDF 提取文本

```bash
pip install pymupdf   # 注意 import pymupdf（fitz 旧名已弃用）
python3 -c "
import pymupdf
doc = pymupdf.open('年报.pdf')
with open('年报.txt','w',encoding='utf-8') as fh:
    for i,page in enumerate(doc):
        fh.write(f'=== PAGE {i+1} ===\n')
        fh.write(page.get_text())
"
```

### Step 2: 章节导航（grep 关键词表）

A股年报/中报章节位置稳定，用 grep 快速定位：

| 目标 | grep 关键词 |
|------|------------|
| 主营业务 | 报告期内公司从事的主要业务 / 主要业务、产品和用途 |
| 收入构成 | 营业收入构成 / 分行业 / 分产品 / 分地区（同一收入三种切分会重复出现） |
| 核心财务 | 主要会计数据和财务指标（营收/归母净利/扣非/经营现金流/EPS/ROE/净资产） |
| 毛利率 | 毛利率比上 / 分行业毛利率 |
| 现金流 | 经营活动产生的现金流量净额 / 现金及现金等价物净增加额 |
| 分红 | 每10股派 / 利润分配预案 / 现金分红总额占利润分配总额 |
| 子公司利润 | 主要控股参股公司分析（净利润/同比） |
| 少数股东 | 少数股东损益 / 重要的非全资子公司（**持股比例！**） |
| 风险 | 公司面临的风险和应对措施（原文风险清单） |
| 担保 | 重大担保 / 违规对外担保 |
| 套保 | 衍生品投资情况（期末敞口/占净资产比） |
| 受限资产 | 所有权或使用权受到限制的资产 |
| 存货/借款 | 存货 / 短期借款 / 长期借款 / 应付票据 |

### Step 3: 同行对比（东方财富 datacenter API，无需 key）

```bash
python3 scripts/fetch_eastmoney.py 000933.SZ --annual   # 主要财务指标，只取年报（统一口径）
python3 scripts/fetch_eastmoney.py 000933.SZ --mainop   # 主营业务构成（分产品收入/成本/毛利率）
```

⚠️ **口径铁律**：不同公司最新报告期不同（有的中报有的 Q1），**对比必须统一取年报**（或同报告期），否则数字严重失真。

### Step 4: 分析框架（自上而下）

1. **商业模式**：主营业务是什么、几个板块、各自收入占比/毛利率
2. **利润构成**：子公司净利 → 减少数股东损益 → 归母净利（注意非全资子公司持股比例！）
3. **盈利驱动**：利润 = 量 × 价 × 成本差；看收入同比 vs 成本同比（售价涨 + 成本降 = 毛利双击）
4. **现金流**：经营现金流/净利 > 1 为佳；看资本开支方向（投入期 vs 收获期）
5. **股东回报**：分红总额、分红率、股息率、回购
6. **风险排查**：见 Step 6

### Step 5: 风险排查清单

- **借款结构**：短期借款占比/半年变化（短债长用 = 续贷压力）
- **受限资产**：货币资金里的保证金/质押水分（账面现金 ≠ 自由现金）
- **存货跌价**：存货规模 × 价格急跌敏感性
- **套保敞口**：衍生品期末金额/净资产比例（空头套保在下跌中反而是保护）
- **原材料依赖**：外购比例（如电解铝企业氧化铝全外购 = 双向挤压风险）
- **电力/资源依赖**：自备电 vs 网电、来水/气候依赖（报告风险章节原文会承认）
- **固定资产/参股减值**：重资产 + 价格长期低位 = 减值雷

### Step 6: 股息敏感性 + 市场定价（用户问"股息/股价多少合适/机构是否低估"时）

- **股息情景表**：利润情景（景气延续/中枢/衰退/归零）× 分红率 → 每股分红 → 现价股息率 + "目标股息率对应股价"（`目标价 = 每股分红 / 目标股息率`）
- **中枢锚定铁律**：用周期中枢利润（近 2-3 年报中位）而非当前峰值利润定"股息锚"；低 PE 是周期股常态，市场在用后视镜定价——讲清楚"当前股价 ≈ 中枢定价还是峰值定价"
- **市场态度三件套**：①实时行情（qt.gtimg.cn，push2 被封时的降级链）②研报评级（reportapi.eastmoney.com，卖方几乎不给周期股目标价=敢讲逻辑不敢给价）③股东户数变化（上升=散户进场=拥挤度信号）+ 中报前十大股东里险资/北向增减
- 完整配方、字段、实例：`references/dividend-valuation-and-market-apis.md`

## Pitfalls

- **东财字段名有拼写错误，照抄别"修正"**：毛利率字段是 `GROSS_RPOFIT_RATIO`（RPOFIT 不是 PROFIT！），收入 `MAIN_BUSINESS_INCOME`、成本 `MAIN_BUSINESS_COST`、收入占比 `MBI_RATIO`（小数）。
- **MAINFINADATA 关键字段**：TOTALOPERATEREVE(营收) PARENTNETPROFIT(归母净利) TOTALOPERATEREVETZ/PARENTNETPROFITTZ(yoy%) EPSJB BPS MGJYXJJE(每股经营现金流) XSMLL/XSJLL(销售毛利率/净利率%) ZCFZL(负债率%) ROEJQ。
- **必须带 UA + Referer header**（Mozilla/5.0 + https://emweb.securities.eastmoney.com/），否则 502/拒。
- **分行业/分产品/分地区重复**：同一营业收入在三个维度各列一遍，别把三者相加。
- **少数股东是隐形税**：非全资子公司净利不能全额归母；归母净利 = 子公司净利合计 − 少数股东损益。看合并报表利润表里的"少数股东损益"行。
- **毛利率同比变化要拆因**：区分"售价涨"（收入↑）vs"成本降"（成本↓）vs 两者双击——报告的经营分析章节通常会直说。
- **报告期口径永远对齐**：年报 vs 年报、中报 vs 中报。
- **周期股先建成本框架**再谈毛利高低（见 references/aluminum-coal-cost-framework.md 的电解铝案例）。

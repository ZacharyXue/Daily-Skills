# 数据分享图设计（小红书竖版 3:4）

把「一只标的的当前位置」做成**一张可截图传播的图**。产物是 1240×1653 PNG，直接发小红书/朋友圈，
也用于看板的对外传播出口。

**触发**：要发小红书/朋友圈的数据图、要把看板结论做成传播物料、要给单只标的出「一图看懂」。

## 一、先分清产物类型（别和监测看板混）

| | 监测看板（`dashboard-style`） | 分享图（本 skill） |
|---|---|---|
| 目的 | 自己分析、长期刷新 | 对外传播、单次发布 |
| 单位 | 一屏 N 只标的 | 一张图 = 一只标的 |
| 结构 | 全指标可折叠、可下钻 | 封面即结论、3 秒能看懂 |
| 风格 | 亮色卡片 + details 折叠 | 白底 + 大数字 + 一句对仗标题 |
| 合规 | 页内来源标注 | **必须有「不构成投资建议」固定位** |

两者共享同一套数据（都走 `data-source-router`）和同一套配色语义（见第五节），但排版目标相反：
看板求「信息全」，分享图求「一条信息被记住」。

## 二、封面五层框架（2026-10 定稿）

自上而下五层，每层只回答一个问题：

| 层 | 回答的问题 | 实现 |
|---|---|---|
| **系列栏** | 这是谁的第几期？ | `ETF 观察 EXP.001 ｜ 本期第 4/10 只 ｜ 一图看懂一只标的` |
| **标签行** | 它是哪类资产、现在什么位置？ | ●类型（KIND） ●估值状态 ●月份 |
| **矛盾标题** | 核心张力是什么？ | 金色大字对仗句（第三节） |
| **数据区** | 贵还是便宜、跌了多少？ | 主位估值分位 + 分位条 + 副位 + 五格数据 |
| **该看什么** | 这只该盯哪个指标？ | 一行中性观察指引（`indices_meta.WATCH`） |

底部固定：`<一句价格×估值关系> · YYYY-MM-DD · 数据：<来源> · 不构成投资建议`。

**系列栏的两个编号是两回事**，都要印：
- `EXP.NNN` = **期号**，跨天首次生成 +1，同日重跑不跳号（改文案重出图不会乱涨），状态落 `share_issue.json` 随工程 commit
- `第 i/total 只` = 标的在本期的位置，编号始终绑定同一只标的

## 三、矛盾标题：本 skill 的核心资产

把核心张力压成**一句对仗短句**（14 字内），可脱离图片单独传播。
写法：名词对名词 / 肯定对否定，例如「**收息是真的，位置是贵的**」「**PE 的便宜，PB 的真相**」。

**必须是规则生成的，不能写死**——行情变了标题要跟着变（红利跌到分位 20% 时，
"位置是贵的"就成了错话）。规则（`share_card.py::make_hook`）：

| 条件 | 输出 |
|---|---|
| PE≥80 且 PB≥80 | 红利类→`收息是真的，位置是贵的`；其他→`盈利是真的，价格是贵的` |
| PE≤25 且 PB≥40（**背离**） | `PE 的便宜，PB 的真相` |
| PE≤20 且 PB≤35 且回撤进度≥50% | `便宜是真的，跌也是真的` |
| PE≤20 且 PB≤35 | `估值趴下了，价格还立着` |
| PE≥80 / ≥60 | `价不便宜，得靠盈利追上` / `位置偏高，安全垫不厚` |
| PE≤35 | `位置不贵，等的是盈利` |
| 中位 | `不上不下，最费耐心` |
| **无 PE、有 PB**（非中证编制） | 按 PB 走资产端口径：`资产不便宜，价格先跌` 等 5 档 |
| 无 PE 无 PB | 退回回撤：`跌得够深，位置够低` / `刚跌一点，位置还高` / `跌了一段，位置在中途` |

⚠️ **规则只描述位置，不给买卖结论**（与「给各维度位置、不给综合结论」的既定偏好一致）。
加新模板时守住这条，否则标题会变成荐股。

## 四、数据区：三级降级 PE → PB → 回撤

主位永远显示**当下最有信息量的那个口径**：

1. **有 PE**：主位 PE 分位（近 5 年，中证官网历史序列自算）+ 右侧并列 PB 分位（近 10 年，天天基金）
2. **无 PE 但有 PB**（港股通红利低波、国证成长100 等非中证编制）：**把 PB 提到主位**
   —— 曾出现「PE 拿不到就显示『无估值数据』，而 PB 97% 明明在手」的自相矛盾
3. **两者都没有**（外盘：标普/纳指/黄金）：主位改用当前回撤

配套规则：
- 拿不到的指标**整块不渲染**，不留一排「—」
- 底部「位置解读」的文案要跟主位口径一致：`generate.view()` 在 PE 缺失但有 PB 时，
  改用资产端描述（原为「估值数据缺失」，会与主位显示的 PB 97% 打架）
- **PE/PB 背离（差 ≥25pt）时把 ⚠ 提示带进黑框**：否则「位置解读：赔率与胜率都占优」
  会被读成「PE 低 = 可买」，而资产端可能根本不便宜

## 五、配色语义（PE/PB 两列必须同源）

分位 → 颜色统一走一个函数（`zone_of`），**绝不各写一套**：

| 分位 | 颜色 | 语义 |
|---|---|---|
| ≥90 | 红 `#e11d48` | 最贵的十分之一 |
| ≥70 | 橙 `#f59e0b` | 偏高 |
| ≥40 | 蓝 `#0ea5e9` | 中位 |
| ≥10 | 绿 `#22a06b` | 偏低 |
| <10 | 深绿 `#16a34a` | 最低区间 |

其他语义色固定：**金色 `#a16207`** = 矛盾标题（白底上用暗金，纯金黄对比度不够）；
**红色 = 破位/贵**、**绿色 = 站上/便宜**（MA20 破位标红、站上标绿）；
标签行圆点颜色复用上面这套，不另造。

> 曾踩：PB 列少写「中位=蓝」档，导致 PE 40-70 显示蓝、PB 40-70 显示绿，两列颜色语义打架。

## 六、排版约束

- 画布 **1240×1653**（小红书 3:4），`overflow:hidden` —— **内容超高会被静默裁掉**，
  且截图看不出来（只是底部没了）
- 新增区块后**必须重算高度**。压缩优先级（本次实测腾出约 250px 的顺序）：
  外框 padding → 数据区字号（`big` 148/`big2` 110）→ 标题字号（h1 70 / hook 52）
  → 各区块 margin-top → 数据格 padding
- 页面截图后**必须肉眼验收**（vision 看一次），重点看：底部页脚是否还在、
  有没有文字重叠、长句是否换行挤压

## 七、文案套路（可迁移到长文/博客/朋友圈）

2026-10 从成熟的「每天讲懂一家公司」类账号（小红书「小叮当拆财报」NO.83 中远海控）拆出来的写法，
**与本 skill 的封面框架同源**，写长文时直接用：

1. **开头 N 字白话讲生意，零术语**：「它做两件事：把货装进箱子漂洋过海，在码头装卸」
2. **反转型数据开场**：先给一个坏数字，再拆开发现方向相反（累计 −23% vs 单季 Q2 +29%）
3. **设问驱动结构**：每段用「为什么会这样？」「它算不算…？」「它凭什么…？」当入口
4. **机制解释必配放大倍数**：不说「周期性强」，说「收入 +94.85% → 归母 +800.06%」
5. **每段末尾放一句可截图的金句**（对仗/否定式）：「率是固定的，被切的那块利润不是」
6. **口径分歧摊开讲、不选边**：同一指标给两种算法 + 点出差异只在一处
7. **给可验证判据，不给结论**：「三季报单季扣非 ≥ 90 亿，利润就算跟上了运价」
   —— 这跟本 skill「给位置不给结论」是同一套哲学，且能制造回访
8. 固定位：免责声明 + 系列编号 + 分类标签

## 八、踩坑（实测）

- **⚠️ `dd_progress` 是小数（0.58），不是百分数**：规则里按 `>= 50` 比较 →
  「回撤进度 95%」被判成「刚跌一点，位置还高」（成长ETF 实测踩到）。
  入口处统一归一化：`if prog <= 1: prog *= 100`
- **markdown `**` 会漏进图里**：分享图直接渲染字符串，所有从看板 `view()` 取来的文案
  都要 `.replace("**", "")`（正文、警告、金句三处都要，漏一处就显示星号）
- **改 Python 别用 `s.index(锚点)` 定位**：`headline()` 和 `build_card()` 都以
  `    p = r.get("pe5_pct")` 开头，锚点会命中**前一个函数**，把后一个函数整段删掉
  （本次实测：`make_hook` + `build_card` 被一起删没）。改用唯一性断言
  `assert s.count(a) == 1`，或直接整文件重写
- **期号只按日期递增**：同一天反复出图不该跳号，否则改一次文案涨一个期号

## 九、代码位置

| 东西 | 路径 |
|---|---|
| 生成器 | `ZacharyXue.github.io/etf-dashboard/share_card.py`（镜像：`zach-skills/industry-monitor-dashboard/references/instances/etf/`） |
| 静态语义 | 同目录 `indices_meta.py`：`META`（指数是什么/代表什么）+ `KIND`（类型标签）+ `WATCH`（该看什么） |
| 动态解读 | 同目录 `generate.py::view()`（估值面/价格面/综合三段，行情变了自动变） |
| 期号状态 | 同目录 `share_issue.json` |
| 产物 | `public/exports/share/*.png` |
| 渲染器 | chrome-headless-shell（路径见 `share_card.py::CHROME`） |

**改文案对齐原则**：静态语义（这只标的"是什么"）进 `indices_meta.py`；
动态解读（"现在什么位置"）留在 `generate.py::view()`。两者分开，
避免行情变了观点还写死在文件里。

# 海螺(及A股)财报经营/分红数据提取 —— 可复用配方

数据源：东方财富公告接口 → 公告PDF → pymupdf提取文本 → 正则解析。全程免费、无需登录。
适用：任何 A 股上市公司财报里的**细分经营数据**(产销量/吨数据/分红)，东财 datacenter 只给财务摘要(营收/净利/毛利/ROE/负债率)，**产销量、吨毛利、吨售价、分季度吨成本、每股派息**只在中报/年报正文里。

## 1. 拉公告列表，定位定期报告 PDF
```
GET https://np-anotice-stock.eastmoney.com/api/security/ann?sr=-1&page_size=40&page_index=1&ann_type=A&client_source=web&stock_list={code}&f_node=1&s_node=1
```
返回 `data.list[]`，每条含 `title`、`art_code`、`notice_date`。定期报告 PDF URL = `https://pdf.dfcfw.com/pdf/H2_{art_code}_1.pdf`。

### ⚠️ 头号坑：半年度报告会把「年度报告」误配
`"年度报告" in "2026年半年度报告"` 为 True(子串)。`list_ann(kind)` 必须区隔：
```python
if kind == "半年度报告": hit = "半年度报告" in t
else: hit = ("年度报告" in t) and ("半年度" not in t)   # 年报要排除半年度
if hit and "摘要" not in t: ...
```

## 2. PDF → 文本
`pymupdf` (系统python3/venv 均有，注意 `import pymupdf` 非 `fitz`)。逐页 `page.get_text()`，加 `=== PAGE N ===` 分页标记。

## 3. 提取经营数据(半年报「分行业销售情况」段)
文本形如：`本集团水泥熟料自产品销量为1.21 亿吨，同比下降3.96%；自产品销售收入286.35 亿元，同比下降16.49%；自产品销售成本222.02 亿元...自产品综合毛利率为22.46%`
```python
m_sales = re.search(r"自产品销量为\s*([\d.]+)\s*亿吨", txt)
m_rev   = re.search(r"自产品销售收入\s*([\d.]+)\s*亿元", txt)
m_cost  = re.search(r"自产品销售成本\s*([\d.]+)\s*亿元", txt)
m_gm    = re.search(r"自产品综合毛利率为\s*([\d.]+)%", txt)
m_yoy   = re.search(r"自产品销量为[\d.]+\s*亿吨.*?同比(下降|上升)([\d.]+)%", txt, re.S)  # 适配空格/跨行
```
**倒算（口径与披露毛利率核验一致）**：
```
吨售价 = 销售收入亿×1e8 / (销量亿吨×1e8)
吨成本 = 销售成本亿×1e8 / 销量
吨毛利 = 吨售价 - 吨成本
验证: 吨毛利/吨售价×100 ≈ 披露综合毛利率   (53.17/236.65=22.47% vs 披露22.46% ✓)
```
> 结论可信度的锚：倒算毛利率必须 ≈ 披露毛利率，否则口径错。

## 4. 提取分红(年报「利润分配」段)
文本：`2025 年度全年每股派发现金红利0.85 元人民币`
```python
m = re.search(r"全年每股派发现金红利\s*([\d.]+)\s*元", txt)   # 全年(含中期+末期)
if not m: m = re.search(r"每股派发现金红利\s*([\d.]+)\s*元", txt)  # 末期兜底
股息率 = 每股派息 / 现价 × 100
```
> 注意：若正则只匹配到「末期」而非「全年」，说明全年那条没抓到(常见于分「中期X元+末期Y元」两处)。优先找带「全年」字样的合计值。

fetch.py 的 `_report()` 读它，三个 getter 分别取 ton_gross_margin/ton_cost/sales_yoy/dividend_yield，渲染来源标「海螺财报PDF提取」。

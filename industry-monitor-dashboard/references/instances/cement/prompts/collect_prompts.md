## ① 分区域 P.O42.5 均价（华东 / 华南）
**要给的数据**：华东、华南 P.O42.5 散装均价（元/吨，最新一周）+ 数据日期。
**来源建议**：数字水泥网 cn-cement.com 分区域价、水泥人网、卓创、百年建筑网公开摘要。
**重要性**：价格组最优先，但华南海螺市占率高、华东是主战场——分区域能看「修复是不是全国性的，还是个别区域拉涨」。
**信号**：华东/华南均价站上 300+ 且连涨 2-3 周 = 区域止跌。

## ② 海螺提价函 发布 / 执行率
**要给的数据**：海螺水泥本月/本周发布的提价函（P.O42.5 上调多少元/吨）+ 实际落地执行率（%）。
**来源建议**：海螺官网/公众号公告、数字水泥网快讯、水泥人网、东财公告。
**信号**：提价函发布 + 落地率 >70% = 修复确认（你有提价函发布就等于价格止跌的第一信号）。

```
{"id":"price_hike","name":"海螺提价函/执行率","value":{"额":<上调元>,"执行率":<百分比>},"date":"YYYY-MM-DD","note":"<摘录>","group":"价格组"}
```

## ③ 全国水泥产能利用率 / 熟料线运转率
**要给的数据**：全国熟料线运转率 / 水泥产能利用率（%），最近一月。
**来源建议**：数字水泥网（会员）、中国水泥协会、百年建筑网。
**信号**：从 ~50% 升到 55-60%+ = 供给收缩/需求回暖。

```
{"id":"capacity_util","name":"水泥产能利用率","value":<百分比>,"unit":"%","date":"YYYY-MM","note":"<来源>","group":"量组"}
```

## ④ 地产新开工 / 施工面积 同比
**要给的数据**：全国房地产开发新开工面积（万平方米，最新月，同比%）、施工面积同比。
**来源建议**：国家统计局（本机被拦，需人工）、东财宏观、新浪财经、《中国房地产报》摘要。
**信号**：新开工降幅收窄（如 -30%→-20%）= 水泥需求止跌的先行。

```
{"id":"housestart","name":"地产新开工同比","value":<百分比>,"unit":"%","date":"YYYY-MM","note":"<来源>","group":"量组"}
```

## ⑦ 供给/出清组（CR10、海螺市占率、错峰执行、关停数、产能置换）
**要给的数据**（逐项，能拿几项给几项）：
- 水泥行业 CR10（前10家产能集中度 %）
- 海螺市占率（%）

**信号**：CR10 上行 + 海螺市占率 18%→20%+ + 错峰严格执行 + 置换减量 = 软出清推进。

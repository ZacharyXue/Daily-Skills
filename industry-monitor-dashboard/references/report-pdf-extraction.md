# A股定期报告 PDF → 经营数据/分红提取（已验证）

从公开定期报告（东方财富公告 PDF）提取上市公司的**吨经营数据**与**分红/股息率**，作为看板"盈利组/成本组/量组"的自动来源。中报/年报都能自己拿——**别误判成"需人工"**，用户明确纠正过这点。

## 流程
1. 东财公告接口找最新**定期报告**（见 data-sources.md §5）→ 拿 `art_code` → PDF URL `https://pdf.dfcfw.com/pdf/H2_{art_code}_1.pdf`。
2. 下载 PDF（`User-Agent` + `Referer`），`pymupdf` 提取全文（`fitz` API 已弃用，`import pymupdf`）。
3. 正则定位经营段 → 计算 → **用披露毛利率核验**。

## 关键正则（海螺水泥 600585 实测）
- 自产品销量：`自产品销量为\s*([\d.]+)\s*亿吨`
- 自产品收入：`自产品销售收入\s*([\d.]+)\s*亿元`
- 自产品成本：`自产品销售成本\s*([\d.]+)\s*亿元`
- 自产品毛利率：`自产品综合毛利率为\s*([\d.]+)%`
- 销量同比：`自产品销量为[\d.]+\s*亿吨.*?同比(下降|上升)([\d.]+)%`（用 `re.S`，因空格/换行）
- 分红(年报)：`全年每股派发现金红利\s*([\d.]+)\s*元`（末期 0.61 + 中期 0.24 = 全年 0.85）

## 换算
- 吨售价 = 收入(×1e8) ÷ 销量(×1e8)；吨成本 = 成本 ÷ 销量；吨毛利 = 售价 − 成本。
- **核验**：`吨毛利 ÷ 吨售价 × 100` 应 ≈ 披露毛利率。实测 22.47% vs 披露 22.46%（吻合才可信）。
- 股息率 = 全年每股派息 ÷ 现价 × 100（现价用腾讯 qt.gtimg.cn）。实测 0.85/18.24 = 4.66%。
- 成本结构（成本费用分析表）：单位生产成本合计（原材料/燃料动力/折旧/人工/其他，元/吨），燃料动力占比最大（海螺燃料动力 93.55 元/吨占57.35%，印证煤是最大成本项）。

## Pitfalls
- **公告标题匹配**：`"年度报告" in title` 误配「半年度报告」（子串）→ 必须 `"半年度" not in title`。
- **PDF 文本列对齐+换行**：表格数字被拆到多行，简单正则失效。用 `re.S` + `\s*`；关键数值（合计/燃料动力）常跨列，优先用披露的"毛利率/销量/收入/成本"组合倒算，避免直接抠成本表末行。
- **亿 vs 亿吨**：都是 1e8，别混（收入亿元 vs 销量亿吨）。
- **报告期口径**：吨经营数据用半年报/年报；分红用年报。列表里两种报告都抓。
- **下载**：PDF 较大(2-3MB)，提取用后台跑避免前台超时被杀。

## 沉淀
提取结果写 `cache/report_helluo.json`，fetch 读它填充对应指标（status 标"财报"），来源显示"海螺财报PDF提取"。每次新财报(年报4月底/中报8月底)跑一次 `extract_report.py`。

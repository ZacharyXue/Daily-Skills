# 需求周期股 vs 价格周期股 + 净资产 ROE 锚定估值

分析低 ROE 重资产股 / 需求见顶行业股（如水泥海螺、钢铁）时使用。**先分清周期类型，再选估值方法。**

## 1. 两种周期的分野（最重要）

| 类型 | 代表 | 需求/价格 | 盈利能否回前高 | 估值方法 |
|------|------|----------|:---:|---------|
| **价格周期股** | 电解铝(神火)、煤炭、铜 | 价格波动、需求仍在 | ✅ 能 | 周期中枢净利 × 倍数 |
| **需求周期股** | 水泥(海螺)、钢铁、地产链 | **需求永久性下行** | ❌ 不能 | 净资产 ROE 锚定 |

**判断信号**：
- 价格周期：商品有全球/全国统一价，需求平稳或增，利润弹性来自价格（能涨回高点）
- 需求周期：**营收已从峰值大幅回落且难回**（海螺 2021 峰 1680 亿 → 2025 仅 825 亿腰斩）；日本水泥当年需求见顶后下滑 65% 是永久性
- 🔴 **需求周期股用"近N年平均净利当正常化盈利"本身就是乐观假设**——不是周期反弹，是永久下滑

## 2. 净资产 ROE 锚定估值法（需求周期 / 低 ROE 重资产股）

核心：**账面净资产 BPS 高低不重要，重要的是资产能生多少钱（ROE）。**

```
合理 PB = 长期 ROE ÷ 要求回报率
合理股价 = BPS × 合理 PB
要求回报率（A股困境/周期股）取 8%-12%，常用 10%
```

**海螺实例（BPS=36.46，现价17.46 → PB 0.48）**：
| 长期 ROE 情景 | 合理 PB | 合理股价 | vs 现价 |
|:---:|:---:|:---:|:---:|
| 守住 4.5% | 0.45 | 16.4 元 | ≈现价 |
| 略回升 5% | 0.50 | 18.2 元 | +4% |
| 塌方 3% | 0.30 | 10.9 元 | **-37%** |

**要点**：
- 关键变量是**长期 ROE 能不能守住**，不是当下 PB 低不低
- PB 0.48 深度破净 ≠ 便宜：若 ROE < 资金成本，净资产会"贬值"（名义账面值 ≠ 实际价值）
- 现价 ≈ ROE 4.5% 对应合理价 → "不贵但无安全垫"

## 3. 需求周期股芒格提示

- 头号死法 = **需求永久下滑**（营收回不去），不是债务爆雷——高负债同行死得更早（水泥里天山亏 72.9 亿 vs 海螺低杠杆微赚）
- 成本优势护城河在需求下行期只能「比别家晚死」，不能「活得更好」——猎物（需求）在缩水
- 定位通常是「平庸生意·便宜价（可交易，不可重仓）」，价值陷阱候选

## 4. 快速判断路径

```
拿到低 ROE 重资产 / 需求见顶行业股：
1. 看营收是否已从峰值大幅回落（回不去 → 需求周期）
2. 拉历史年度净利曲线确认"景气顶→谷底"形态
3. 用 ROE 锚定法算合理 PB，对照现价（东财 datacenter BPS + 腾讯行情 PB）
4. 芒格：死法清单看需求，能力圈外 → 只可交易不可重仓
```

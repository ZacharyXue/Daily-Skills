# 新药研发管线分析（医药股 / ST摘帽判断）

分析医药公司新药公告（如"XX进入II期临床"）或评估创新药管线价值时使用。

## 新药研发全流程（做什么 + 累计上市概率 + 投入占比）

```
药物发现 → 临床前 → I期 → II期 → III期 → NDA申报 → 审评 → 上市（总计10-15年）
```

| 阶段 | 做什么 | 累计上市概率¹ | 投入占比 | 时长 |
|------|--------|:---:|:---:|:---:|
| ① 药物发现 | 找靶点、筛化合物、优化先导 | ~2%* | ~10% | 3-6年 |
| ② 临床前 | 动物实验证安全+有效（毒理/药代）| ~32% | ~15% | 1-2年 |
| ③ I期 | 20-80人健康人，安全性/耐受/剂量 | ~52% | ~10% | 1-2年 |
| ④ II期 | 100-300人患者，疗效+最佳剂量 | ~28% | ~20% | 2-3年 |
| ⑤ III期 | 数百~几千人，大规模确证 | ~58% | **~35%** | 2-4年 |
| ⑥ NDA/审评 | 提交全部数据，药监局审评 | ~85% | ~5% | 1-3年 |
| ⑦ 上市后 | 四期/真实世界监测 | — | ~5% | 持续 |

¹ 各阶段累计（从进入该阶段起最终上市）概率；¹药物发现标~2%因样本笼统。

**阶段间转换率（P(TS)**，进了这步能挺到下一步）：
`临床前→I期 65% / I→II 70% / II→III 45%(重灾区) / III→NDA 60% / NDA→获批 90%`

**核心认知**：
- **幂衰减**：候选药从进入临床到上市综合成功率约 **5-8%**
- **II期是最容易失败的坎**（45% 转换率）——新药公告若只说"进II期"，离上市还很远
- **III期最烧钱**（约占总投入35%），II期占20%；II期时累计投入通常仅几千万，III期才是烧钱大头

## 医药公司分析要点

1. **区分主价值来源**：公告药品是"远期期权"还是"核心现金流"？
   - 垄断存量业务（如人福的麻醉镇痛药：管制批文+芬太尼系列垄断）才是真正价值锚
   - 创新药管线对存量为主的公司是"锦上添花"，不是主要价值
2. **ST 摘帽 vs 研发管线是两码事**：因控股股东资金占用被 ST 的公司，摘帽靠解决合规/资金占用，**靠不下新药临床**。评估这类公司要聚焦"ST问题是否缓解"，而非新药进度。
3. **突破性公告判断**：获临床批件 / 进 II 期 = 正常研发动作，中性信息，对股价影响小。真正有分量的是 上市获批 / 关键 III 期数据读出。
4. **新药公告的经济账**：即便品种上市，若是成熟市场（如镇痛药）也只是补充产品，不带来爆发增长——测算时用"存量主业盈利 × 合理倍数"，把管线当期权而非现金流。

- 公告 PDF：飞书群附件 → lark-cli user 身份下载（`im +chat-messages-list` → 找 file_key → `im +messages-resources-download`）
- 东财 datacenter MAINFINADATA（历年净利/ROE/负债率缓解）：`filter=(SECUCODE%3D%22<code>.SH%22)`
- 资产负债表 RPT_DMSK_FN_BALANCE（货币资金/总负债）：`filter=(SECUCODE...)`

使用「保守经济账」场景时，用多家公司横向对比 + 多情景 PE 表，强调**ST 压制下现价往往已反映悲观预期，上行靠摘帽估值修复**。

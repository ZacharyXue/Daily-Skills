# 约翰·聂夫 —— 低市盈率逆向（Low P/E 价值派）

> 来源：聂夫（John Neff）管理温莎基金 31 年（1964-1995），年化收益 13.7%，跑赢标普 500 达 3.1 个百分点。代表作《约翰·聂夫的成功投资》（John Neff on Investing）。子皓低 PE 偏好 + 「便宜的好公司被错杀」逻辑与此派最契合。

## 一句话画像
> **专买「被冷落的好公司」——低市盈率 + 高股息 + 盈利增长的「总回报」组合，而非单看估值便宜。他买的不是「便宜」，是「暂时受委屈的好生意」。**

## 核心方法论：低市盈率投资法（Low P/E）

| 选股硬指标 | 阈值 | 内层逻辑 |
|---|---|---|
| **市盈率** | 低于行业平均 60% 以下 | 市场给它的价格远低于内在价值 |
| **盈利增长** | 未来 7-10 年复合增长 > 市场平均 | 便宜要有「增长」托底，不是死便宜 |
| **股息率** | 相对稳定、有增长 | 总回报的「安全垫」部分 |
| **总回报比例** | (盈利增长 + 股息率) / 市盈率 越高越好 | 核心公式，见下 |

**聂夫最核心的「总回报」公式**：
```
总回报 = 盈利增长率 + 股息率 + 估值修复（回归合理PE）
```
他选的股票往往**现价 PE 低 + 有增长 + 有分红**，一旦市场重新认可，三者叠加形成超额收益。

## 逆向哲学（聂夫 vs 市场）

- **买「没人要的」**：机构持仓比例低、分析师覆盖少、话题冷门的公司——正是市场情绪暂不入场的地方。
- **卖「大家都抢的」**：当一只票从冷门变成热门、市盈率被推到高位时**坚决卖出**。
- **「冷门≠烂公司」**：他反复强调要区分两种低市盈率——**好公司被暂时错杀（机会）** vs **烂公司本来就该便宜（陷阱）**。判断标准是「盈利增长」和「分红」能不能托底。

## 实战检视清单（对一只低PE股逐条打勾）

1. 市盈率是否明显低于行业/历史中枢？
2. 未来几年盈利能否稳定增长（不是一次性爆量）？
3. 是否有持续、且增长的分红（股息率是否厚）？
4. 是不是「市场嫌弃、机构冷落」的冷门股？
5. **关键**：低 PE 是因为「暂时坏消息压制」还是「基本面已永久恶化」？——后者是价值陷阱，坚决避开。

## 与巴菲特/芒格的互补（对撞）

- **巴菲特**看「伟大公司合理价」；**聂夫**看「被冷落公司的便宜价」——聂夫**更容忍瑕疵、更主动逆人群**，愿意为「困境反转/暂时性利空」承担额外不确定性。
- **芒格**警惕「便宜 + 坏生意 = 价值陷阱」；聂夫会用「**盈利增长 + 股息能托底吗**」来区分「错杀」vs「该便宜」——这正是芒格那个担忧的**可执行解法**。

## 使用注意

- 聂夫视角**最契合子皓「低 PE + 高股息 + 增长」的选股偏好**，是「低估值陷阱」判断的**正面补充**（芒格管「别买假的便宜」，聂夫管「认准真错杀」）。
- 对 ST/困境反转类标的：聂夫会问「**这个低 PE，是不是把'坏消息'已经定价完了？盈利增长和分红能撑住吗？**」——回答不了这两问，就按「该便宜」处理，不碰。

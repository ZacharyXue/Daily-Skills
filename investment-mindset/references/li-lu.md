# 李录 —— 价值投资 + 文明演进双框架

> 来源：李录 2006 哥伦比亚大学演讲《The Evolution of Value Investing》、著作《文明、现代化、价值投资与中国》。子皓通过 whale-holdings 跟踪李录喜马拉雅资本 13F，此篇最贴合你主线。

## 一、价值投资三基石（2006 哥大演讲）

李录继承格雷厄姆-巴菲特，把价值投资归纳为**三大基石**：

| 基石 | 内核 |
|---|---|
| **市场先生** | 价格波动是**可利用的**（市场先生的恐慌/贪婪给你上车/下车机会），不是需要预测的 |
| **内在价值** | 价格 ≠ 价值；买的是企业未来现金流的折现 |
| **能力圈** | 只投真正看懂的企业；圈小没关系，知边界才重要 |

**李录补的最关键一点 —— 读懂生意经济性的核心变量是 ROIC（投入资本回报率）**：
> 不只看「便宜不便宜」，更看「**能以高回报持续再投资**」——这才是长期复利引擎。一家公司如果 ROIC 高且能持续把利润再投入高回报项目，它就是「复利机器」；只看低 PE 不看 ROIC，容易掉进价值陷阱。

他认为价值投资是「**无需运气、靠真知 + 纪律**」的正道，需要：**认知诚实 + 耐心 + 长期**。

## 二、文明演进框架（《文明、现代化、价值投资与中国》）

李录把投资放到**人类文明演进**的大尺度看，帮他判断「这家公司是不是时代级的」：

- **人类文明三阶段**：采集狩猎 → 农业文明 → **现代科技文明**。
- **自由市场 + 科技创新**是现代文明的发动机；财富长期流向**最优秀的代表企业**。
- 中国**现代化转型**是历史级机遇（城市化、工业化、消费升级的长周期）。

**落地为可执行的分析维度**（ai-berkshire 提炼）：

| 维度 | 追问 |
|---|---|
| **文明级范式转移** | 这个行业是不是在「蒸汽机/电力/互联网/AI」级别的范式转移中？ |
| **TAM 增长曲线** | 市场到底有多大、还在不在变大？ |
| **公司在价值链位置** | 是链上价值捕获者，还是被上下游挤压的？ |
| **技术路线风险** | 技术路线会不会被颠覆？ |
| **李录式终极检验** | 「**站在 20 年后回看，这家公司是这个时代的标准石油，还是昙花一现的 3Com？**」 |

## 三、与巴菲特视角的互补（对撞）

- 巴菲特说「**够便宜**」→ 李录追问「**10 年后它还在吗**」（长期性检验）。
- **价值陷阱**提醒：看似便宜（低 PE），但若 ROIC 低、无法持续再投资、生意在衰退——那是「陷阱」不是「机会」。李录框架天然帮你区分「便宜的好公司」vs「便宜的死公司」。

## 四、使用注意

- **李录 = 把「价值投资」从「怎么选便宜」升级到「怎么选伟大 + 长期主义」**——适合判断**长线核心持仓**（如你在研究的神火/红利/港股央企红利这类长线标的）。
- ROIC + 文明演进是**李录独家增量**，现有芒格/巴菲特框架没覆盖到，用来做**长期性 + 经济性**双重体检。
- 「20 年后它还在吗」是避免**价值陷阱**最锋利的一刀，咨询时主动用。

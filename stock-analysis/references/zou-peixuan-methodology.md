## 一、《穿透财报》— 读懂报表

bookId `3300075531` · 8.34分 · 41章

### 认识论
- **专业的对立面不是不专业，而是熟练**——读报表要回到会计制度的设计初衷
- **会计 = 经济真相 + 计量差错 + 偏见**；报表是语言，"既有纪实功能，也有文学功能"
- **三表驱动链**：资产负债表是利润表的驱动力（先有能赚钱的资产才能赚钱）→ 利润表是经营性现金流的驱动力（先有权利义务交换才有现金流交换）

### 关键识别点
- **应收账款 vs 合同资产**：坐等收钱=应收；须再追加服务才收钱=合同资产
- **资产减值不得冲回**（固资/无形/长投/商誉）：盈利好转也不得冲回 → 一次减值即永久减记
- **应收款项融资**：仅打算保理/转让、未真正转出 → 与应收没实质区别（防虚增现金）
- **重资产对增值税敏感**：利润薄的行业，资本开支含不含增值税影响净利
- **完全成本法**：失败视为成功之母（不出油的井也资本化）→ 激进、虚增账面资产
- **生物资产="薛定谔的猫"**：无生产成本、生老病死、难核查（扇贝案例）→ 价值不确定

### 舞弊与调节识别
- **幸存者偏差**：只看到回来的飞机，机翼弹孔≠易中弹（样本偏差，A股白酒/成长股认知要警惕）
- **BOT 会计调节**：可调不同阶段利润分布，税法认可，递延所得税查不出
- **资本性负债**从筹资性现金流进出 → 增加舞弊难度（分不清资金来源的公司要警惕）
- **归母/少数股东损益**：子公司亏损按持股比例摊入少数股东，归母要×持股比例还原

## 二、《穿透估值》— 制定价格

bookId `3300111059` · 7.94分 · 34章

### 估值第一性原理
- **财报定下限，产业趋势定上限**：财报是保下限（少亏钱）；趋势决定上限 → 基本面再好的公司，方向错了也赚不到钱
- **超额收益源于预期差/错误定价**——本质是分母（折现率）没调整到位，靠研究能力白拿
- **估值核心要义=前瞻性，兼顾可靠性**：估值没标准答案，很主观
- **PE 由业绩天花板高度决定**：给定折现率，高度确定后增速高一点低一点都一样
- **PE 只对业绩高点有用**：周期股业绩低点的 PE 无意义，天花板倍数可能无限大

### 理论与实战陷阱
- **逻辑链越长，兑现概率越低**：三个80%相乘=51.2%，严谨≠会兑现（se 长链条论证要打折扣）
- **大盘股不能靠梦想支撑，容易"窒息"**
- **绩优股≠跑赢**：2010-2023.7 申万绩优股未跑赢亏损股指数（呼应「质量因子」式红利的伪逻辑）
- **短期业绩的意义在修正预期**，不在业绩本身
- **靠市场非理性赚钱很难持续**：是赚玩家博弈的钱，谁都不比谁聪明

### 案例洞见
- **已投产水电站造价与估值无关**：考虑抵税，报表利润越低、总价值越高（反直觉）
- **外部收益率越低项目越值钱**：市场同类回报不高，反衬公司资源不一般，价值增厚更大
- **戴维斯双击的代价**：无法用业绩证明模式前，任何双击都是透支未来 → 深度回调放大器

## 三、《穿透叙事》— 看懂涨跌（推荐先读，心法层）

bookId `3300208501` · 9.05分 · 33章

### 两套定价机制（全书之纲）
1. **空间叙事**：DCF 分子端"未来现金流"当下并未实际发生——**本质上是一段叙事**
2. **拍卖机制**：不能做空 → 流动性潮汐 → 由最乐观资金定价，展望期极易一次性透支未来涨幅

### 超额收益的唯一来源
- **只能来自叙事的变化**：t1 展望的未来现金流/折现率 ≠ t0 → 分子分母消不掉即有超额
- **先看股价位置及隐含叙事，再谈边际变化**：新旧叙事估值差=涨跌关键；光有"指南针"（边际变化）不够
- **个股与宽基指数重新重合 = 新叙事已完全定价，超额窗口关闭**
- **超额窗口非常短暂**：考验"迅速形成正确认知"；利空出尽常以年计

### 反直觉铁律
- **景气度只能判起点，判不了终点**：怎么涨上去就怎么跌下来；景气尚在反诱人抄底，越抄越低
- **不要轻易抄底，尤其阴跌过程中**：A股向下定价能力弱，难莫名阴跌
- **宁德 vs 银行**：2021-2024 宁德业绩远好于银行，股价相反，3年背离非特例 → 叙事否决业绩
- **连掷5次正先怀疑硬币是否均匀**：别从小样本提炼成功经验（幸存者偏差的实战版）
- **人类天生"相信叙事胜于事实和数据"**——心法层最难克服

### 财务数据的真正定位（点睛）
> 财务数据 = **验证/证伪叙事切换的坐标系**。别执迷静态报表，要看旧叙事→新叙事的切换，及业绩对这种切换的动态验证。

## 与本 skill 的对照用法

| 穿透三书观点 | stock-analysis 对应环节 |
|-------------|------------------------|
| 财报识别舞弊/调节（幸存者偏差、BOT、资产减值） | Phase 5 风险排查、Phase 5.5 治理风险 |
| 财报定下限（少亏钱） | Phase 3-4 财务挖数与利润构成 |

| 杠铃策略（低风险资产长期收益更高） | 保守标的（高股息/稳定ROE）估值锚 |

**财报看下限（别亏）、估值看上限（别追）、叙事看拐点（别贪）——超额收益只藏在叙事变化与价值回归的缝隙里。**

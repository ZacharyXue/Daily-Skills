# 白马股安全边际估值框架（合理PB = ROE/r + Gordon 增长下限）

> 适用范围：**ROE 稳定、非周期**的白马/消费/成长股（白电/食品饮料/品牌制造 e.g. 海尔、美的、贵州茅台等）。
> 目的：回答「现价到底有没有安全边际、贵不贵」，并把「安全边际何时被增长放缓吞噬」**量化**出来。
> 对比：周期股（铝/煤/钢铁）走 `cycle-stock.md`；这类 ROE 稳定股用本框架。
> ⚠️ 前提：适用于 ROE 可持续的公司。ROE 中枢若下移，整套估值跟随缩水。

## 一、核心公式（必背）

```
① 合理PB = ROE ÷ r            （r = 要求回报率，价值投资者常用 8%~12%）
② 合理价  = 合理PB × 每股净资产（每股净资产 = 现价 ÷ 现PB 反推）
```

- 这是把「净资产能生多少钱（ROE）」折算成「该给多少倍净资产（PB）」的锚定：ROE 越高、要求回报越低 → 合理 PB 越高。
- 要求回报 r 的选取：行业/公司确定性越高越可低（8%），确定性存疑/波动大偏高（12%）。**多档展示（8/10/12）做敏感性**，别只算一档。

## 二、市场隐含要求回报（最直观一栏）

```
市场隐含r = ROE ÷ 现PB
```

| 隐含 r | 解读 |
|---|---:|
| 低（如美的 6.3%）| 市场只要求很低回报就愿意持有 = **定价偏贵/给足质量溢价** |
| 高（如海尔 10.3%）| 市场要求高回报才买 = **定价便宜/被折价** |

> 两家同是白电龙头，隐含 r 一个是 6%、一个是 10%，差值就是「市场给的质量溢价」在估值上的体现。

## 三、Gordon 成长模型：量化「增长下限」（进阶）

安全边际的严格形式——把增长率 g 也纳进去：

```
合理PB = (ROE − g) / (r − g)      （g = 可持续增长率，要求 g < r 且 g < ROE）
```

**反解市场隐含增速 g\***（令合理PB = 现PB）：

```
g* = (ROE − PB×r) / (1 − PB)
```

| 判定 | 含义 |
|---|---|
| 实际增长 > g\* | 现价**低估**，有安全边际 |
| 实际增长 < g\* | 现价**高估**，安全边际为负 |

**关键洞察**：g\* 就是「市场当前价格默认的未来永续增速」。对比公司**实际/近期增速**即可判断现价透支还是压缩了增长预期：
- 美的：r=10% 时 g\*=+5.4%，但中报增速已从 +14% 放缓到 +1.7% → 现价**已预支高增长**，安全边际薄/为负；
- 海尔：r=8% 时 g\*=-5.8%、r=10% 时 g\*=-0.7% → 市场**连零增长都没信**，现价压缩了大量增长预期 → 安全边际厚。

## 四、操作清单（白电/ROE 稳定白马）

1. 拉 ROE（2025 年报 + 中报年化，两个都看，**中报年化下滑要警惕 ROE 中枢下移**）
2. 拉每股净资产 = 现价 ÷ 现PB，排 8/10/12% 三档合理价
3. 算市场隐含 r = ROE ÷ PB，和中报年化 ROE 对照
4. 跑 Gordon 反解 g\*，对比公司近期实际增速 → 判断「预支增长」还是「压缩增长」
5. **盯一个变量可锁定价值陷阱**：ROE 稳住 → 便宜是机会；ROE 下滑 → 便宜是陷阱（估值随 ROE 中枢下移缩水）

## 五、实例：美的 vs 海尔（2026-08-31）

| 指标 | 美的集团 000333 | 海尔智家 600690 |
|---|---:|---:|
| 2025 年报 ROE | 19.7% | 16.98% |
| 现价 / 现PB | 86.23 / 3.11 | 21.12 / 1.65 |
| 每股净资产 | 27.73 | 12.80 |
| 市场隐含 r | 6.33% | 10.29% |
| r=8% 合理价 | 68.28 (-20.8%) | **27.17 (+28.6%)** |
| r=10% 合理价 | 54.62 (-36.7%) | 21.73 (+2.9%) |
| Gordon 隐含增速 g\* (r=10%) | +5.4% (现增 1.7% → 透支) | -0.7% (零增长已够 → 低估) |
| 中报净利同比 | +1.7% | -14.3%（**剔汇兑≈-2%**，见 forex-profit-trap）|

**一句话**：**美的的现价预支了「持续高增长」，海尔把「零增长」都算进去了**——前者增长一停就戴维斯双杀，后者哪怕零增长也安全。安全边际海尔德厚。

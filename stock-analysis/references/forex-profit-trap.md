# 海外收入高占比公司的「汇率假摔」识别

> 适用范围：海外收入占比高的 A 股（白电/消费电子/出海制造 e.g. 海尔、美的、TCL等）。
> 目的：报表净利常被**汇兑损益**放大或缩小，判断「价值陷阱 vs 经营平稳」前**必须先剔除汇兑噪音**，避免把一次性的会计扰动误读成经营恶化。

## 一、财务费用构成公式（必背）

```
财务费用 = 利息支出 − 利息收入 + 汇兑损益 + 手续费
```

- 制造/白电企业手续费占比极小 → **剩余项 ≈ 汇兑损益**。
- 汇兑损益 = 外币资产/负债折算的会计损益，**非经营性**，随汇率波动，持续性弱。

## 二、反推汇兑（东财 GINCOME 字段）

从 `RPT_F10_FINANCE_GINCOME` 取三个字段：

| 字段 | 含义 |
|---|---|
| `FINANCE_EXPENSE` | 财务费用总额（正=净支出，负=净收入） |
| `FE_INTEREST_EXPENSE` | 利息支出 |
| `FE_INTEREST_INCOME` | 利息收入 |

```python
汇兑+手续费 ≈ FINANCE_EXPENSE − (FE_INTEREST_EXPENSE − FE_INTEREST_INCOME)
```

- **利息净额**（`FE_INTEREST_EXPENSE - FE_INTEREST_INCOME`）通常**稳定**；
- 财务费用若**由负转正/大幅波动**，先看是不是**汇兑这一栏**在动，而非利息。

## 三、判别：经营性 vs 非经营性

| 信号 | 判别 |
|---|---|
| 利息净额稳定，波动全在"剩余项"（汇兑） | **非经营性** → 可剔除 |
| 利息支出上升 / 融资成本恶化 | **经营性** → 需重视 |
| 汇兑损失伴随毛利率上升、现金流转正 | 主营健康，是"报表假摔" |

## 四、剔除汇兑后的真实经营（权重法）

```
剔汇兑后归母 ≈ 报表归母 ± 汇兑×税率×(1−少数股东%)
```

- 税率 ≈ 所得税 ÷ 利润总额；少数股东% 取近年均值。
- 若"剔汇兑后"与去年基本持平、且毛利率向上 → **经营平稳，被汇兑放大**。

## 五、案例：海尔智家 600690（2026中报）

| 分项 | 2026中报 | 2025中报 | Δ |
|---|---|---|---|
| 财务费用总额 | +11.03 | -3.51 | +14.54 |
| 利息净额 | 1.33 | 5.38 | -4.05 |
| **汇兑+手续费（反推）** | **+9.70** | **-8.89** | **+18.59** |

- 汇兑一正一负差出 18.6 亿税前 → 税后归母 ≈ 14.7 亿，正好解释 -17.2 亿的归母下滑大部。
- **剔除汇兑后归母 ≈ -2%**（而非 -14.3%），毛利率 27.23% 仍升、现金流为正。
- 结论：是「汇率假摔」，非经营崩塌；资产端毛利升级、收入仅微降。

## 六、保留项（别过度"豁免"）

1. **人民币趋势性升值** → 汇兑持续侵蚀海外利润折算（结构性背景项，非经营恶化），要盯**套保/海外净敞口**。
2. **扣非归母仍含汇兑**（汇兑在经常性损益内），所以"剔汇兑的扣非"才是真经营节奏——别把扣非-20%直接当经营崩塌，先剔汇兑再看。
3. 汇兑是双刃剑：今年损失，下季可能收益，**判别持续性关键看汇率趋势 + 套保策略**，而非单季数字。

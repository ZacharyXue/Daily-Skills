# 股息敏感性测算 + 行情/机构/资金面 API

周期股（铝/煤/钢铁等）分析的后半程工具：**极端情况下股息还剩多少**、"保持 X% 股息率对应股价多少"、以及判断"机构/市场是否低估"所需的实时行情、研报评级、股东户数数据源。

## 一、股息敏感性测算（核心方法）

### 1.1 输入参数（全部来自报告 + 行情）

```python
total_shares = 22.49  # 亿股（总股本，年报披露）
price = 25.83         # 实时价（见下方行情 API）
payout_ratio = 0.446  # 分红率 = 分红总额 / 归母净利（年报"利润分配预案"）
```

### 1.2 情景表（利润情景 → 分红 → 股息率 → 目标价）

```python
scenarios = [
    ('A 景气延续: H2=H1 全年95.6亿', 95.6, 0.45),
    ('B 温和回落: H2=H1×0.7 全年81.3亿', 81.3, 0.45),
    ('C 回归2025: 全年40亿', 40.0, 0.45),        # ← 周期中枢，最重要的锚
    ('D 铝价-30%: 全年15亿', 15.0, 0.40),
    ('E 极端: 全年0', 0.0, 0),
]
for name, profit, pr in scenarios:
    div = profit * pr                      # 分红总额(亿)
    dps = div / total_shares               # 每股分红
    yield_now = dps / price                # 现价股息率
    px_for_3pct = dps / 0.03               # 3% 股息率对应股价
```

### 1.3 输出表（回答"极端情况股息还有多少" + "3%股息率股价多少"）

| 情景 | 全年净利 | 分红总额 | 每股分红 | 现价股息率 | 3%对应股价 |
|------|--------:|--------:|--------:|:---------:|----------:|
| A 景气延续 | 95.6亿 | 43.0亿 | 1.91元 | 7.4% | 63.76元 |
| B 温和回落 | 81.3亿 | 36.6亿 | 1.63元 | 6.3% | 54.22元 |
| C 回归2025(中枢) | 40亿 | 18.0亿 | 0.80元 | 3.1% | 26.68元 |
| D 铝价-30% | 15亿 | 6.0亿 | 0.27元 | 1.0% | 8.89元 |
| E 极端归零 | 0 | 0 | 0 | 0% | 无法维持 |

### 1.4 解读要点（给用户讲清楚）

- **用周期中枢利润锚定，不用当前峰值**：周期股分红能力随利润大幅波动，静态股息率做买入决策最危险。神火中枢 ≈ 40-60 亿（看 2024/2025 年报），对应每股分红 0.8-1.2 元 → 3% 股息率合理价位 27-40 元。
- **当前股价 ≈ 中枢定价**（25.83 元 vs 中枢价 26.68 元）：市场没给 2026 暴利定价，也没为最坏情况折价。
- **低 PE 是周期股常态**：8.4x PE 定价的是"2025 盈利水平"而非 2026 爆发 → 市场在"看后视镜"。
- **高股息陷阱**：最坏情景（铝价-30%）股息率掉到 1%，股价要跌 65% 才回到 3% —— 现价买的是"铝价不崩"的期权。
- 周期股 45% 毛利率处于历史高位时明确说"赚的是周期钱不是成长钱"。

## 二、实时行情 API（push2 被封时的降级链）

`push2.eastmoney.com/api/qt/stock/get` 常被拒（502/断连），按此顺序降级：

### 2.1 腾讯行情（A股，最稳）— `qt.gtimg.cn`

```
https://qt.gtimg.cn/q=sz000933     # 前缀: sh/sz + 6位代码
```

返回 `~` 分隔字段，关键下标：
- `[3]` 现价、`[4]` 昨收、`[5]` 今开、`[39]` PE(动)、`[41]` 52周高、`[42]` 52周低、`[45]` 总市值(亿)、`[46]` PB

```python
req = urllib.request.Request('https://qt.gtimg.cn/q=sz000933',
    headers={'User-Agent':'Mozilla/5.0'})
txt = urllib.request.urlopen(req, timeout=10).read().decode('gbk')  # 注意 gbk
parts = txt.split('~')
price = float(parts[3])
```

### 2.2 期货行情（沪铝等）— `push2delay.eastmoney.com`

```
https://push2delay.eastmoney.com/api/qt/stock/get?secid=113.alm&fields=f43,f57,f58,f170
# secid: 113.alm=沪铝主连  133.AHD=氧化铝主连(不稳)  142.ALI=LME铝(不稳)
# f43=最新价(单位:元/吨,×1)  f170=涨跌幅
```

注意：氧化铝/LME 的 secid 常返回 null，沪铝主连 `113.alm` 稳定。

## 三、机构/资金面 API（判断"机构是否低估"）

### 3.1 研报评级 — `reportapi.eastmoney.com`

```
https://reportapi.eastmoney.com/report/list?pageSize=20&beginTime=<1年前>&endTime=<今天>
  &pageNo=1&code=000933&qType=0&fields=&industry=*&rating=&ratingChange=
```

返回 `data[]`：`publishDate`、`orgSName`(机构名)、`title`(含评级倾向)。
- 看标题方向即可（"盈利弹性释放""高分红价值凸显" = 看多），`ratingName` 常为空。
- **卖方几乎不给周期股目标价**（`indvObjectivePrice` 为空是常态）——这本身是有用信号：券商敢讲逻辑不敢给价。

### 3.2 股东户数（散户拥挤度）— datacenter

```
https://datacenter.eastmoney.com/securities/api/data/v1/get
  ?reportName=RPT_HOLDERNUMLATEST&columns=ALL
  &filter=(SECURITY_CODE%3D%22000933%22)
  &pageNumber=1&pageSize=5&sortTypes=-1&sortColumns=END_DATE
```

返回 `result.data[]`：`END_DATE`、`HOLDER_NUM`(户数)、`HOLDER_NUM_RATIO`(较上期%)。
- **户数上升 = 筹码从机构流向散户 = 阶段性高位信号**（"大V买入"叙事已传导到散户层的客观指标）。

### 3.3 主力资金流向 — `push2.eastmoney.com/api/qt/stock/fflow/kline/get`

```
secid=0.000933&fields1=f1,f2,f3,f7&fields2=f51..f65&klt=101&lmt=30
klines[]: "日期,主力净流入,小单...", parts[1] 单位元
```

不稳（push2 可能被封），降级方案是直接看股东户数 + 前十大股东（中报/年报披露，`持股比例`+`报告期内增减`）。

### 3.4 前十大股东（买方动向）— 从报告 PDF 直接读

grep `前10名股东|持股比例|香港中央结算|中国人寿|泰康`：
- **香港中央结算** = 北向资金，增减代表外资态度
- **险资**（人寿/泰康/社保）加减仓 = 高股息逻辑的长线资金动向
- 自然人股东大幅增减 = 大户信号

## 四、实例速查（神火股份 2026-08-16）

- 现价 25.83 元，总市值 580.9 亿，PE(动) 8.44，PB 2.10（腾讯行情）
- 沪铝主连 23,945 元/吨（push2delay）
- 2025 年报每股分红 0.80 元，分红率 44.6%，当前股息率 3.10%
- 近 1 年研报 12 篇全看多、无一给目标价（reportapi）
- 股东户数 12.94 万，环比 +3.85%（散户进场，拥挤度上升）
- 中报前十大股东：北向 +2065 万股、中国人寿传统 +1913 万股、泰康分红 -195 万股 → Q2 险资+北向净加仓

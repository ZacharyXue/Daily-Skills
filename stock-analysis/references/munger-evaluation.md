# 芒格逆向评估（投资哲学校验）

被 `stock-analysis` SKILL.md Phase 8 索引。用芒格的体系对标的做最终评估，
产出"生意质量 × 价格安全边际 × 机会成本"定位结论。**先找死法，再找理由。**

---

## 1. 逆向思维：先问"这笔投资会怎么死"

列出标的的**所有结构性弱点**，把每个弱点对应到"最可能的死法"：

| 死法 | 对应弱点 | 概率 |
|------|---------|:----:|
| ① 商品/核心产品价格崩塌 | 价格是否处历史高位区？ | 中/高 |
| ② 成本端反转 | 原材料外购？成本是否不可控？ | 高 |
| ③ 供给受限 | 产能依赖外部条件（电价/来水/政策）？ | 中 |
| ④ 财务杠杆 | 短债滚动？受限资金？续贷压力？ | 低-中 |
| ⑤ 误判陷阱 | 大V/散户进场？叙事已传播到散户层？ | 正在发生？ |
| ⑥ 管理层背叛 | 控股股东资金占用/违规担保/大额关联交易？ | 排查治理 |
| ⑦ 资产减值 | 大额商誉/存货/长投，价格长期低位？ | 中 |

**逆向结论模板**："最可能的死法不是 X，而是 Y（把周期高位盈利当常态 / 成本回归吃掉利润 / 叙事过热 / 治理掏空）。"

## 2. 能力圈自测（芒格最严厉的一关）

> "如果这个生意有三个决定性变量，我一个都预测不了，那它就在我能力圈之外。"

- 列出标的利润的**前 N 大驱动变量**（商品价？汇率？政策？管理层？）
- 问：**这些变量我能预测吗？**
  - 全可控（品牌/网络效应/客户粘性）→ 能力圈内（喜诗糖果型）
  - 全不可控（大宗商品价/来水/宏观）→ 能力圈外（电解铝型）
- 能力圈外的生意：要么不碰，要么**承认自己在做"择时交易"而非"价值投资"**

**量化判据**：给自己评估的利润/价格能**打入 20% 以内误差**吗？打不进 = 能力圈边缘/之外，重仓需极强安全边际补偿。

## 3. 护城河可维持性审计

| 护城河来源 | 强度(★) | 可维持性 | 备注 |
|-----------|:------:|:-------:|------|
| 成本优势（一体化/区位） | | ✅/⚠️/❌ | 是区位红利还是结构性壁垒？ |
| 品牌/定价权 | | | 能提价不流失客户？ |
| 网络效应/规模 | | | 时间越久越值钱？ |
| 资源/牌照 | | | 政策给的是否可持续？ |
| **关键输入锁定** | | | **最贵的原材料/能源是否自控？** |

**芒格式评语模板**："护城河里最重要的砖——XX 和 YY——都是租来的/外购的。成本优势是区位红利，不是结构性壁垒。"

**可维持性 3 问**：这护城河 10 年后还在吗？竞争对手复制的成本和时间是？护城河在变宽还是变窄（涨价权/份额趋势）？

## 4. 误判心理扫描（现在的市场情绪坐标）

用芒格的人类误判心理学清单，扫当下市场状态（扩到 6 条）：

- **社会认同倾向**：大V/散户是否在买入？股东户数环比变化？（散户进场=叙事高潮信号）
- **对比误判**：高股息 vs 理财/存款——"价格吸引"被包装成"价值保证"？高股息是"确定性收益"还是"周期高位的静态回报"？
- **过度乐观**：近期高增长被线性外推成长期趋势？
- **稀缺倾向/避免不一致**：机构是否集体看多但无人给目标价（敢讲逻辑不敢给价）？
- **损失厌恶/沉没成本**：已持有亏损，是"扛到回本"真实逻辑，还是不愿认错的沉没成本？
- **锚定效应**：把"历史分红最高"或"上市以来高点"当锚，据此算的估值是否偏高（周期股尤其——用周期中枢而非峰值锚定）？
- **逆向确认**：这个标的最"芒格式便宜"的时刻，是不是市场最嫌弃它的时候？

**扫描产出**：当前叙事处于"无人问津 → 部分认可 → 大V背书 → 散户蜂拥"哪个阶段？阶段越靠后，安全边际要求越高。

## 5. 管理层质量评估（芒格：人先于生意）

> "选择与管理层做生意的对象，优先于选择生意本身——一个平庸管理层能毁掉最好的生意。"

结合 Phase 5.5 治理排查，单独评估管理层**能力 + 诚信 + 股东友好度**：

| 管理层维度 | 信号 | 打分 |
|-----------|------|:----:|
| **诚信/穿透性** | 财报是否"藏事"（会计政策激进、大额非经常损益、少提减值）？历史有没有造假/资金占用/违规记录？ | |
| **资本配置能力** | 留存收益投去哪？是投回高ROE主业，还是乱并购/多元化/理财躺平？ | |
| **再投资回报** | 留存利润的新增投资ROE ≥ 存量ROE 吗？（若留存不留回报=毁股东价值） | |
| **股东回报政策** | 分红/回购是否慷慨且可持续？还是死抠现金不回报（账面现金大量闲置）？ | |
| **言行一致** | 公告/推销的"看好方向"和实际资本开支、资产投向是否一致？（对应你"基金经理言行一致"的标的版本） | |
| **利益绑定** | 管理层持股/增持？还是高位减持/质押套现？ | |

**关键交叉**：治理风险（Phase 5.5）给出的 🔴/🟡 信号直接喂进这里——一票否决级信号（非标审计/实控人高质押/资金占用）会让整个管理层维度降级，无论生意多好。

## 6. 机会成本思维（芒格决策第一法则）

> "所有投资决策，本质上都是拿**当下所有可选项里最优的那个**做标尺。没有最好，只有相对最好。"

评估不能孤立"这公司好不好"，必须和**替代选择**对比：

| 替代选择 | 期望年化 | 确定性 | 备注 |
|---------|:------:|:------:|------|
| 现金/货币基金 | 1-2% | 极高 | 无风险下限 |
| 国债/存款 | 2-3% | 极高 | 无风险基准 |
| 同类更优公司 | ?% | 中 | 同一个钱更该放哪？ |
| <本题的标的> | ?% | 中 | 与上述对比 |

**机会成本判据**：只有当本题标的的**确定性折后回报 > 无风险回报 + 风险补偿**，且**相对同类标的没有明显更好的**，才值得买入。否则"它便宜"不够——**"它是我现在能拿到的相对最优"**才行。

**契合你的估值锚**：3% 股息率锚 ≈ 机会成本的另一面——用"这公司分红+成长能不能跑赢无风险收益"来反推合理买价，正是机会成本在估值端的落地。

## 7. Lollapalooza 效应（多重因素同向叠加）

> "当多个因素同向叠加时，会互相强化产生非线性的击穿性结果——好事全来或坏事全来。"

把上面各维度打分汇总成**正向/负向两个清单**，判断是否出现共振：

| 方向 | 是否叠加 | 因素 |
|-----|:------:|------|
| 正向共振 | 是/否 | 低PE + 周期底部 + 成本优势 + 分红提升 + 需求回暖 + 叙事未起 |
| 负向共振 | 是/否 | 周期高位 + 成本回归 + 叙事过热 + 散户进场 + 治理瑕疵 |

**关键判据**：
- **多个负向因素同时出现 = 经典击穿区**（高估值+高位+过热+坏治理），回避优先；
- **多个正向因素同向 = 非线性的超额机会**，但警惕"太顺"本身是情绪高潮信号；
- 单独一个坏因素可接受，**多个叠加的坏因素 = 系统性风险**，安全边际要指数级提高。

## 8. 最终定位：生意质量 × 价格安全边际

```
                    生意质量（可预测性/定价权）
                          高
            伟大公司·合理价│ 伟大公司·便宜价 ← 芒格甜蜜区
           （可长期持有）  │ （all-in 机会）
           ──────────────┼──────────────
            平庸公司·合理价│ 平庸公司·便宜价
           （回避）       │ （可交易，不可持有）
                          低
      ← 当前价格安全边际 →
```

**低估值陷阱识别（你低PE偏好的补充）**——芒格最反直觉的一句：

> "以合理价买伟大公司，远好过以便宜价买平庸公司。"

| 情形 | 判断 |
|------|------|
| 便宜 + 好生意 + 好管理层 | ✅ 芒格甜蜜区，可重仓 |
| 便宜 + 平庸生意 + 平庸管理层 | ⚠️ **价值陷阱**——"便宜"是"该便宜"（低ROE+资本黑洞），不是错杀 |
| 便宜 + 周期高位盈利 | ⚠️ 低PE是周期股常态，是"峰值定价"不是"中枢定价" |
| 合理价 + 伟大生意 | ✅ 长期持有优先；（你偏好低PE，但别为便宜牺牲生意质量） |

**逐项打分（★）：**

| 芒格维度 | 打分 | 评语 |
|---------|:----:|------|
| 生意可预测性 | ★☆☆ | 核心变量在能力圈外？ |
| 护城河可维持性 | ★★☆ | 成本优势真实但输入未锁定？ |
| 管理层质量(诚信+配置) | ★★☆ | 治理干净吗？钱留对了方向吗？ |
| 机会成本(相对最优) | ★★☆ | 是不是当下能拿到的最优？ |
| 当前价格安全边际 | ★★☆ | 高股息是亮点，但买在周期高位区？ |
| 能力圈适配 | ★☆☆ | 芒格本人不会投？但愿意学周期的人可以？ |

## 9. 复利与持有框架

> "没人愿意慢慢变富——但快富通常是通过复利+时间，而不是一把梭。"

- **判断时间尺度**：这是能拿 **5-10 年**的生意（伟大公司），还是只配持有 1-2 年等周期反转（周期股/困境反转）？
  - 伟大公司：买点不重要（合理价即可），**持有时间>选股点**
  - 周期/反转：卖点决定成败，**入场时间>选股质地**
- **隐含年化回报**：用最保守情景算出隐含年化（分红+涨价+估值回归），对比无风险利率是否足够补偿。
- **避免"死亡螺旋"**：为"持有2-3年等周期"做准备 ≠ "被套牢后自我安慰价值投资"——区分主动判断与被动躺平。

## 10. 芒格式结论模板

> "这是一家在正确位置拥有真实成本优势、对股东慷慨的公司。但它的护城河是'租来的'——关键输入不在自己手里，利润取决于我看不懂的价格；管理层配置现金的方向也待验证。**它值得被尊敬，不值得被长期持有；值得被交易，不值得被买入并忘记。** 正确姿势：众人恐慌、利润难看时买；众人传颂、大V背书时，想清楚自己在跟谁交易。放在机会成本天平上，它是否优于我现在能拿到的其他选择？"

## 11. 行动启示（给用户的芒格式收尾）

1. **别问"会涨到哪"，问"错了亏多少"**：用最坏情景（价格回成本线+成本回归）算利润与股息，能接受再买
2. **好公司 ≠ 好的"现在的"股票**：区分"好公司"（经营面）与"好股票"（价格面）
3. **机会成本优先**：不是"它便宜"就买，而是"它是我当前可选项里相对最优"才买
4. **管理层透明优先**：宁可要"略贵但干净、钱留对方向"的，不要"便宜但治理模糊"的
5. **买入纪律**：只在你算得清"最坏情况不致命"时买；为"持有2-3年等周期"做准备，不为"高股息冲动"
6. **终极测试**：*"如果今天你手里没有这只股票，你会在当前价买入吗？"* —— 犹豫 = 驱动你的是叙事（社会认同），不是推理

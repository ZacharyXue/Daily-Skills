# 芒格逆向评估（投资哲学校验）

被 `stock-analysis` SKILL.md Phase 8 索引。用芒格的四个核心武器对标的做最终评估，
产出"生意质量 × 价格安全边际"定位结论。**先找死法，再找理由。**

## 1. 逆向思维：先问"这笔投资会怎么死"

列出标的的**所有结构性弱点**，把每个弱点对应到"最可能的死法"：

| 死法 | 对应弱点 | 概率 |
|------|---------|:----:|
| ① 商品/核心产品价格崩塌 | 价格是否处历史高位区？ | 中/高 |
| ② 成本端反转 | 原材料外购？成本是否不可控？ | 高 |
| ③ 供给受限 | 产能依赖外部条件（电价/来水/政策）？ | 中 |
| ④ 财务杠杆 | 短债滚动？受限资金？续贷压力？ | 低-中 |
| ⑤ 误判陷阱 | 大V/散户进场？叙事已传播到散户层？ | 正在发生？ |

**逆向结论模板**："最可能的死法不是 X，而是 Y（把周期高位盈利当常态 / 成本回归吃掉利润 / 叙事过热）。"

## 2. 能力圈自测（芒格最严厉的一关）

> "如果这个生意有三个决定性变量，我一个都预测不了，那它就在我能力圈之外。"

- 列出标的利润的**前 N 大驱动变量**（商品价？汇率？政策？管理层？）
- 问：**这些变量我能预测吗？**
  - 全可控（品牌/网络效应/客户粘性）→ 能力圈内（喜诗糖果型）
  - 全不可控（大宗商品价/来水/宏观）→ 能力圈外（电解铝型）
- 能力圈外的生意：要么不碰，要么**承认自己在做"择时交易"而非"价值投资"**

## 3. 护城河可维持性审计

| 护城河来源 | 强度(★) | 可维持性 | 备注 |
|-----------|:------:|:-------:|------|
| 成本优势（一体化/区位） | | ✅/⚠️/❌ | 是区位红利还是结构性壁垒？ |
| 品牌/定价权 | | | 能提价不流失客户？ |
| 网络效应/规模 | | | 时间越久越值钱？ |
| 资源/牌照 | | | 政策给的是否可持续？ |
| **关键输入锁定** | | | **最贵的原材料/能源是否自控？** |

**芒格式评语模板**："护城河里最重要的砖——XX 和 YY——都是租来的/外购的。成本优势是区位红利，不是结构性壁垒。"

## 4. 误判心理扫描（现在的市场情绪坐标）

用芒格的人类误判心理学清单，扫当下市场状态：

- **社会认同倾向**：大V/散户是否在买入？股东户数环比变化？（散户进场=叙事高潮信号）
- **对比误判**：高股息 vs 理财/存款——"价格吸引"被包装成"价值保证"？
- **过度乐观**：近期高增长被线性外推成长期趋势？
- **稀缺倾向/避免不一致**：机构是否集体看多但无人给目标价（敢讲逻辑不敢给价）？
- **逆向确认**：这个标的最"芒格式便宜"的时刻，是不是市场最嫌弃它的时候？

## 5. 最终定位：生意质量 × 价格安全边际

```
                    生意质量（可预测性/定价权）
                          高
            伟大公司·合理价│ 伟大公司·便宜价 ← 芒格甜蜜区
           （可长期持有）  │ （all-in 机会）
           ──────────────┼──────────────
            平庸公司·合理价│ 平庸公司·便宜价
           （回避）       │ （可交易，不可持有）
                          低
      ← 当前价格安全边际 →
```

逐项打分（★）：

| 芒格维度 | 打分 | 评语 |
|---------|:----:|------|
| 生意可预测性 | ★☆☆ | 核心变量在能力圈外？ |
| 护城河可维持性 | ★★☆ | 成本优势真实但输入未锁定？ |
| 管理层股东回报 | ★★★ | 分红/回购/激励？国企里罕见地股东友好？ |
| 当前价格安全边际 | ★★☆ | 高股息是亮点，但买在周期高位区？ |
| 能力圈适配 | ★☆☆ | 芒格本人不会投？但愿意学周期的人可以？ |

## 6. 芒格式结论模板

> "这是一家在正确位置拥有真实成本优势、对股东慷慨的公司。但它的护城河是'租来的'——关键输入不在自己手里，利润取决于我看不懂的价格。**它值得被尊敬，不值得被长期持有；值得被交易，不值得被买入并忘记。** 正确姿势：众人恐慌、利润难看时买；众人传颂、大V背书时，想清楚自己在跟谁交易。"

## 7. 行动启示（给用户的芒格式收尾）

1. **别问"会涨到哪"，问"错了亏多少"**：用最坏情景（价格回成本线+成本回归）算利润与股息，能接受再买
2. **好公司 ≠ 好的"现在的"股票**：区分"好公司"（经营面）与"好股票"（价格面）
3. **买入纪律**：只在你算得清"最坏情况不致命"时买；为"持有2-3年等周期"做准备，不为"高股息冲动"
4. **终极测试**：*"如果今天你手里没有这只股票，你会在当前价买入吗？"* —— 犹豫 = 驱动你的是叙事（社会认同），不是推理

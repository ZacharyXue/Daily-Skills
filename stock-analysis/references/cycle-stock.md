# 周期股分析模板（商品价格驱动型公司）

适用：利润由大宗商品价格主导的资源/能源股（电解铝、煤炭、铜、油、化工等）。
被 `stock-analysis` SKILL.md Phase 7 索引。**核心原则：用周期中枢估值，不用周期顶部估值。**

## 1. 先判断周期位置（最重要的一步）

```bash
# 拉商品历史价格，算当前价的分位（近3-5年）
# 例：沪铝主连（东财 K 线接口）
python3 - <<'EOF'
import urllib.request, json
from collections import defaultdict
url = 'https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=113.alm&fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56&klt=101&fqt=0&beg=20230101&end=20261231&lmt=2000'
req = urllib.request.Request(url, headers={'User-Agent':'Mozilla/5.0'})
d = json.loads(urllib.request.urlopen(req, timeout=15).read().decode())
vals = [float(k.split(',')[2]) for k in d['data']['klines']]
now = vals[-1]
pct = sum(1 for v in vals if v < now) / len(vals) * 100
print(f'现价 {now:.0f}，处于近3年 {pct:.0f}% 分位')
EOF
```

- **分位 >70%**：周期高位，警惕"低 PE 陷阱"（高景气利润拉低 PE）
- **分位 <30%**：周期底部，可能真便宜（但可能继续便宜）
- 高位+高毛利+大V看多 = 典型的周期顶部信号组合

## 2. 利润敏感性模型（核心工具）

输入：产能、归母系数（非全资子公司折算）、吨/单位净利锚点、成本弹性。

```
利润 = 基准利润 + (商品价 - 基准价)/1000 × 弹性
弹性 = 产量 × 归母系数 × 1000 / 1e8  (亿/千元)
```

**两种情景必须都算**：
- **情景A（当前成本结构外推）**：弹性大——成本不变、价格纯传导（乐观）
- **情景B（成本回归正常）**：弹性小——原材料成本随行就市，吃掉部分涨价收益（保守）

> ⚠️ 铁律：**周期股利润的暴增/暴减，往往一半来自商品价、一半来自成本波动**。只盯商品价会严重高估。典型例子：电解铝公司 2026H1 暴利 = 铝价涨 + 氧化铝跌 双因素；氧化铝一旦回归，利润腰斩。

## 3. 盈利能力的真实构成（拆解清单）

- 商品价格（收入端）→ 判断周期位置
- 成本结构（成本端）→ 判断护城河：电力/原材料/人工/折旧，哪项可控？
  - **自给 vs 外购**：氧化铝自给率高 = 成本锁死；100% 外购 = 成本不可控（最大软肋）
  - **自备电 vs 网电**：自备电+坑口煤 = 区位红利；网电 = 看天吃饭（枯水/电价上调）
- 少数股东分流：非全资子公司（如神火云南持股58.25%）= 归母"隐形税"，利润要先乘持股比例

## 4. 股息与估值（周期股专用）

- **分红率**：看公司承诺（成熟期无大资本开支 → 分红率可维持高位）
- **每股分红 = EPS × 分红率**（注意：EPS 用你假设的利润情景，不是当前报表）
- **3% 股息率反推股价 = 每股分红 / 0.03**
- **周期中枢估值**：用过去 3-5 年平均净利 × 10-15x，或"中性情景净利 × 合理倍数"，别用顶部利润
- 高股息是"价格吸引"，不是"价值保证"——顶部利润算出的股息率会误导

## Pitfalls（周期股专属）

- **低 PE 不是便宜**：周期顶部利润 × 低倍数 = 数字幻觉，用正常化盈利重算
- **情景A/B 要一起看**：成本回归情景通常被市场忽略，但往往更接近现实
- **别把"周期股优等生"当"成长股"**：成本优势+高分红让它像好公司，但它还是周期股，利润弹性是双向的
- **最坏情况测算**：商品价跌到成本线时公司还剩多少利润（煤炭/其他业务底仓）——这是能不能拿住的关键

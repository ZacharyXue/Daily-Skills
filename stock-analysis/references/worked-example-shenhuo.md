# 输出样例：神火股份（000933）2024年报 + 2025年报 + 2026中报

本文件是 `a-share-report-analysis` 的输出形状模板：用户给的原始问题
「先帮我看看他的商业模式主营业务，有多少业务，利润、现金流，股东回报」。
展示每个维度的组织方式与措辞，下次直接套结构、换数字。

## 输出结构对照

### 1. 商业模式与主营业务

- 公司定位一句话：铝煤双主业 + 铝箔延伸的资源型企业，核心是电解铝，煤炭提供低成本电力+利润缓冲。
- 业务表格：业务 / 收入(亿元) / 占比 / 毛利率 / 说明（产能、储量、品牌、主体）
- 商业模式精髓（强调护城河）：煤-电-铝一体化 → 自备电厂+水电，用电成本低于同行；双基地布局（新疆火电+云南水电铝）。

### 2. 业绩趋势

跨年表：
| 指标 | 2023 | 2024 | 2025 | 2026H1 | H1同比 |
（营收、归母净利、扣非、经营现金流、EPS、加权ROE、总资产、净资产）

要点措辞：
- "2023→2025 净利逐年下滑（电解铝+煤价下行周期），但 2026H1 大幅反转：单半年净利 47.8 亿 > 2025 全年 40.1 亿"
- "反转主因：电解铝毛利率从约 25-30% 飙到 45.3%（涨价 + 低成本电力）"
- 周期股要交代谢：这个毛利率是周期高位。

### 3. 现金流质量

表格：经营/投资/筹资三大活动净额 + 现金净增 + 期末余额。
要点措辞："经营现金流 72 亿 vs 净利 47.8 亿 = 1.5 倍，利润含金量高；资本开支仅 2.4 亿，处于收获期而非投入期"。

### 4. 股东回报

表格：年度 / 每股分红 / 分红总额 / 占净利比例。
要点措辞："分红率逐年提升 41.8%→44.6%，股息率约 4-5%；明确成熟期定位、现金分红占比≥80% 政策；有回购专户+股权激励"。
注意：中报"不派现"是惯例，分红看年报。

### 5. 综合结论

优点 ✅ 清单（成本护城河 / 业绩爆发 / 现金流强 / 分红高 / 供给约束）+ 风险 ⚠️ 清单（强周期 / 区域集中 / 铝箔占比小）。
一句话总结：**"周期高位、利润爆发的煤电铝一体化龙头，现金流和分红都漂亮，赚的是铝价的钱不是成长的钱"**。

### 6. 结尾可深挖方向

风险章节原文 / 资产负债率 vs 有息负债 / 铝箔产能爬坡 / 同业对比（中国铝业、云铝股份）。

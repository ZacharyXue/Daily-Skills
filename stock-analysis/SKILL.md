# 股票基本面深度分析

一套完整的个股分析流水线：从财报 PDF 到投资结论。**通用框架**适用任何股票；**周期股**（商品价格驱动的资源/能源股）有专门的敏感性分析模板；**芒格逆向评估**作为最终投资哲学校验。

## 触发场景

- 用户发来年报/中报/研报 PDF："分析下这家公司"
- 用户问"商业模式/主营业务/财务风险/同行对比/股息"
- 用户问"XX 公司能不能买"（→ 跑完整流水线）
- 与 `whale-holdings`（大佬持仓跟踪）衔接：看到大佬买了某家公司 → 深挖该公司

## 流水线总览

```
Phase 0 文件就位 → Phase 1 PDF提取 → Phase 2 商业模式 → Phase 3 财务三表
→ Phase 4 利润构成 → Phase 5 风险排查 → Phase 5.5 企业道德与治理风险
→ Phase 6 同行对比 → Phase 7 估值 → Phase 8 芒格逆向评估 → 输出结构化报告
```

各 Phase 通用，周期股在 Phase 7 走 `references/cycle-stock.md` 模板，芒格评估见 `references/munger-evaluation.md`。**所有数据接口（东财 datacenter/腾讯行情/研报/K线）见 `references/data-apis.md`**。

A股聚合技巧与 grep 锚点表见 `references/eastmoney-peer-compare.md`（含固定输出维度七步模板）、电解铝成本框架见 `references/aluminum-coal-cost-framework.md`、股息敏感性+行情降级链见 `references/dividend-valuation-and-market-apis.md`、完整实例见 `references/worked-example-shenhuo.md`。

## Phase 0: 文件就位

- PDF 从飞书消息来 → 检查 Hermes 文档缓存 `~/.hermes/cache/documents/`，若无则提示用户放 `/tmp/<公司名>/`（参考 ttskill-headless skill 的落盘模式）
- 确认文件存在、可读、页数合理（年报 200+ 页正常）

## Phase 1: PDF 文本提取

```bash
python3 scripts/extract_pdf.py /tmp/shenhuo/2026中报.pdf /tmp/shenhuo/2026中报.txt
# 输出: === PAGE N === 分页标记的纯文本
```

- 工具：`pip install pymupdf`（若缺失）
- 提取后 grep 定位关键章节（见下），全文留作引用

## Phase 2: 商业模式拆解（公司是干什么的）

在提取的文本中 grep 并精读：

| 目标 | 关键词 |
|------|--------|
| 主营业务 | `公司主要业务`、`主营业务为`、`主要产品` |
| 收入结构 | `营业收入构成`、`分行业`、`分产品`、`分地区` |
| 毛利率 | `毛利率`、`营业成本` |
| 护城河/优势 | `成本优势`、`核心竞争力`、`一体化`、`产能` |

**产出**：业务板块表（收入占比 + 毛利率）+ 商业模式一句话概括 + 护城河来源清单。

## Phase 3: 财务三表挖数

grep 定位：

| 表 | 关键词 | 关键指标 |
|----|--------|---------|
| 利润表 | `主要会计数据`、`归属于上市公司股东的净利润` | 营收/归母净利/扣非/EPS/ROE |
| 现金流量表 | `经营活动产生的现金流量净额` | 经营/投资/筹资净额 |
| 资产负债表 | `货币资金`、`存货`、`短期借款`、`长期借款`、`资产负债率` | 现金/存货/借款/负债率 |

**关键比率**：经营现金流 ÷ 净利（>1 利润含金量高）；货币资金 vs 短期借款（偿债压力）。

## Phase 4: 利润构成拆解（利润哪来的）

- grep `主要控股参股公司`、`子公司` → 各子公司营收/净利
- grep `持股比例`、`少数股东损益` → 归母口径还原（非全资子公司利润被少数股东分流）
- grep `同比变动原因`、`增减原因` → 毛利率变动归因（涨价？成本降？量增？）

**产出**：利润传导链（子公司汇总 → 少数股东 → 归母）+ 核心利润引擎识别。

## Phase 5: 风险排查（哪里会暴雷）

| 风险类型 | 关键词 |
|---------|--------|
| 负债结构 | `短期借款`、`一年内到期的非流动负债`、`受限资产` |
| 存货跌价 | `存货`、`跌价准备` |
| 减值 | `商誉`、`资产减值`、`长期股权投资` |
| 担保 | `担保`、`反担保` |
| 衍生品 | `套期保值`、`期货`、`衍生品` |
| 自认风险 | `面临的风险`、`风险因素`、`不确定` |

**重点**：上游成本锁定度（原材料外购 vs 自给）、电价/资源依赖、短债滚动压力。

## Phase 5.5: 企业道德与治理风险排查（A股特有雷区）

用户最重视的维度之一（与血统纯不纯正相关）：很多"基本面好"的 A 股死于治理问题，不是经营。**先排雷，再谈质地。**

| 雷区 | grep 锚点 | 危险信号 |
|------|-----------|---------|
| 控股股东资金占用 | `资金占用`、`非经营性占用`、`往来款` | 大股东/关联方长期占用上市公司资金 → 掏空 |
| 违规担保 | `违规担保`、`对外担保`、`为关联方担保` | 替别人扛债，担保额/净资产比过高 |
| 关联交易 | `关联交易`、`重大关联交易`、`关联方` | 定价不公允、频繁购销、利益输送 |
| ST/立案 | `ST`、`立案调查`、`被立案`、`监管措施` | 立案审查、问询函密集 → 治理隐患 |
| 审计意见 | `审计意见`、`非标`、`保留意见` | 非标准无保留意见 = 财务可信度打折 |
| 股权质押 | `质押`、`股份质押` | 实控人质押比例高 → 爆仓/被动减持风险 |
| 诉讼/涉诉 | `诉讼`、`仲裁`、`冻结` | 大额诉讼、存款冻结（海螺有 0.44 亿冻结案例） |
| 商誉 | `商誉`、`减值` | 高价并购留下的大额商誉 = 未来减值雷 |

**排查要点**：
- **ST 原因要分清"治理"还是"经营"**：人福是被前股东资金占用（治理），主业自愈中 → 摘帽修复逻辑成立；若 ST 源于主业崩塌则另当别论。
- 非标审计意见、实控人高质押、频繁关联交易 → 一票否决级别信号。
- 治理瑕疵的公司，**估值折价 = 赌它修复**，不是"便宜"；算价时要用"已定价治理风险"而非无风险折现。

**产出**：治理风险清单（每个雷区：信号 → 严重度 🔴/🟡/🟢 → 是否影响买入逻辑）。

## Phase 6: 同行对比

```bash
python3 scripts/peers_compare.py 000933.SZ 601600.SH 000807.SZ
# 东方财富 datacenter API，统一报告期对比
```

- 对比维度：营收/归母净利/EPS/ROE/毛利率/净利率/每股经营CF/负债率
- ⚠️ **口径必须统一**：年报用年报、中报用中报，混比会失真
- 产出：同行定位表 + "成本结构差异"解读（同涨同跌对谁有利）

## Phase 7: 估值与敏感性

- 通用：PE/PB/股息率（行情接口）→ 与同业、历史分位对比
- **周期股**：走 `references/cycle-stock.md`（商品价格敏感性模型 + 情景A/B + 3%股息率反推股价）
- 消费/成长股：偏重 DCF 逻辑、增速与估值匹配

## Phase 8: 芒格逆向评估

见 `references/munger-evaluation.md`：逆向死法清单、能力圈自测、护城河可维持性审计、误判心理扫描（社会认同/对比误判/过度乐观）。产出"生意质量 × 价格安全边际"定位结论。

## 输出格式

一份结构化报告：商业模式 → 财务 → 风险 → 同行 → 估值/敏感性 → 芒格评估。用户偏好：表格 + 数据支撑 + 一句话结论，先讲透再落博客。

## Pitfalls

- **PDF 目录页/页眉干扰**：提取文本带 `=== PAGE N ===` 和公司名页眉，grep 时用 `-E` 精确匹配关键词
- **口径混比**：同行对比、同比数据必须统一报告期；年报 vs 中报不可直接比
- **归母 vs 合并净利**：子公司利润要先乘持股比例，别把合并报表净利当归母
- **周期股用周期均值估值**：高景气年份的低 PE 是"数字幻觉"，参考 `references/cycle-stock.md`
- **东方财富接口**：push2 行情接口偶发拒绝，用腾讯行情 `qt.gtimg.cn` 兜底；datacenter 接口字段名要现查（用 `columns=ALL` 先 dump 一条）
- **少数股东分流**：非全资子公司（如神火云南 58.25%）利润要打折，这是"隐形税"
